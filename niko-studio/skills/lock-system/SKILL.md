# LOCK故事核心系统 (Lock System)

> **skill_id**: `lock-system`
> **version**: `1.0.0`
> **domain**: `结构技法`
> **triggers**: `LOCK系统`, `故事核心`, `主角目标`, `对抗`, `故事前提`, `Logline`

---

## 🎯 技能定位

LOCK系统是詹姆斯·斯科特·贝尔（James Scott Bell）提出的故事核心检验框架。它确保每个故事都具备商业潜力和戏剧张力的四大支柱。本技能聚焦于如何利用LOCK系统构建扎实的故事概念，并将其与特鲁比的"故事设计原则"相结合。

---

## 📐 核心理论：LOCK系统

### L - Lead（主角）

主角必须是一个**引人注目的人**。

| 要求 | 描述 |
|------|------|
| **可辨识性** | 读者能在人群中一眼认出他 |
| **同理心** | 读者愿意跟随他的旅程 |
| **内在冲突** | 拥有需要克服的弱点或需求 |
| **独特性** | 不是模板化的类型人物 |

**关键问题**：
- 主角是谁？
- 他有什么与众不同的特质？
- 读者为什么会关心他？

---

### O - Objective（目标）

主角想要什么？目标必须**具体且迫切**。

| 目标类型 | 描述 | 示例 |
|---------|------|------|
| **外部目标** | 可见的、具体的追求 | 找到凶手、赢得比赛、拯救女儿 |
| **内在目标** | 心理或精神层面的需求 | 获得认可、克服恐惧、找到归属感 |

**迫切性检验**：
- 如果主角不追求这个目标，会发生什么？
- 有没有"时钟"在滴答作响？（截止日期）
- 风险是否足够高？（死亡威胁：职业、心理或生理）

---

### C - Confrontation（冲突/对抗）

谁在阻挡主角？对手必须**比主角更强**。

| 对手要求 | 描述 |
|---------|------|
| **力量优势** | 对手在某些方面比主角更强大 |
| **目标竞争** | 对手与主角争夺同一个目标 |
| **道德论点** | 对手有自己认为正确的理由 |
| **攻击弱点** | 对手专门攻击主角最大的弱点 |

**核心原则**：
> 对手不仅是阻碍者，更是主角的**"分身"（Double）**——他们追逐同一个目标，但持有截然相反的价值取向。

---

### K - Knockout（冲击结尾）

结局是否有力？

| 结局要求 | 描述 |
|---------|------|
| **必然性** | 结局是主角之前行为的必然结果 |
| **惊奇性** | 以观众未预期的方式呈现 |
| **情感共鸣** | 让观众获得满足感或深刻触动 |
| **价值位移** | 发生从正到负或从负到正的剧烈变化 |

**检验问题**：
- 结局是否依赖巧合？（如果是，必须用伏笔修正）
- 主角是否在压力下做出了两难选择？
- 观众会记住这个结局多久？

## 🎨 故事设计原则 (Designing Principle)

特鲁比提出的概念：用一句话概括故事的**深层逻辑和独创性叙事策略**。

### 经典案例

| 电影 | 故事设计原则 |
|------|-------------|
| 《教父》 | 用童话策略讲述小儿子如何成为新王 |
| 《卡萨布兰卡》 | 在战争废墟中，一个愤世嫉俗者重新找回牺牲精神 |
| 《肖申克的救赎》 | 自由存在于心灵，而非围墙之外 |

### 设计原则的功能
1. **统一性**：所有情节都必须服务于这个原则
2. **独特性**：让你的故事区别于同类型作品
3. **深度**：将表面故事与深层主题连接

## 🔧 LOCK系统 + 七大关键步骤

将LOCK系统与特鲁比的七大关键步骤结合，形成完整的故事骨架：

| 步骤 | 内容 | 对应LOCK |
|------|------|---------|
| **1. 弱点与需求** | 主角开场时的缺陷 | L (Lead) |
| **2. 欲望** | 主角的具体外部目标 | O (Objective) |
| **3. 对手** | 竞争同一目标并攻击弱点 | C (Confrontation) |
| **4. 计划** | 主角初步的行动策略 | O (Objective) |
| **5. 对决** | 最后的决战形式 | C (Confrontation) |
| **6. 自我揭露** | 主角发现关于自己的真相 | K (Knockout) |
| **7. 新平衡** | 故事结束后的新世界 | K (Knockout) |

## 🤖 AI 提示链

### 第一步：LOCK四要素定锚
```
请基于故事灵感，回答LOCK四问：
1. L (Lead)：主角是谁？有什么引人注目的特质？
2. O (Objective)：他想要什么？目标是否具体且迫切？
3. C (Confrontation)：谁在阻挡他？对手是否比主角更强？
4. K (Knockout)：结局是否有力？是否源于主角的选择？
```

### 第二步：故事设计原则
```
请提炼故事设计原则：
1. 用一句话概括故事的深层逻辑
2. 这个原则如何让故事与众不同？
3. 所有情节是否都服务于这个原则？
```

### 第三步：倒推法构建骨架
```
请按照倒推法生成故事骨架：
1. 先确定步骤7（新平衡）和步骤6（自我揭露）
2. 基于结局，设定步骤1（弱点与需求）
3. 填充步骤2-5
```

### 第四步：质量检验
```
检查清单：
□ 主角是否有清晰的弱点和需求？
□ 目标是否有"时钟"（截止日期）？
□ 对手是否有自己的道德论点？
□ 结局是否依赖巧合？（必须用伏笔修正）
```

## 🎬 四角对立扩展

为了让冲突更加立体，在LOCK的C（Confrontation）基础上，建立**四角对立**角色网络：

| 角色位置 | 价值取向 | 功能 |
|---------|---------|------|
| **主角** | 主要价值观 | 故事的道德中心 |
| **主要对手** | 相反的价值观 | 直接对抗主角 |
| **次要对手A** | 极端化的主角价值观 | 展示主角路径的危险 |
| **次要对手B** | 另一种变奏 | 提供第三视角 |

**示例**（主题：正义）：
- 主角：程序正义至上
- 主要对手：结果正义，不择手段
- 次要对手A：死板的官僚主义
- 次要对手B：虚无主义，认为正义不存在

---

## 💡 核心公式

> **LOCK = Lead（引人注目的主角）+ Objective（迫切的目标）+ Confrontation（强大的对抗）+ Knockout（有力的结局）**

通过LOCK系统，你可以在动笔之前就确保故事具备：
1. **商业潜力**：观众想看的核心元素都在
2. **戏剧张力**：冲突和风险足够高
3. **情感共鸣**：结局能打动人心
4. **结构完整**：从开始到结束逻辑自洽
