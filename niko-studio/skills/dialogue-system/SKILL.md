# 💬 对话系统 (Dialogue System)

> **核心理念**：对话不是角色说了什么，而是角色**没说**什么。好的对话有潜台词，人物嘴上说的和心里想的不一样。

---

## 技能定位

本技能整合了对话创作的完整体系：

| 模块 | 职责 |
|------|------|
| **理论层** | 麦基多重自我、潜台词本质 |
| **技法层** | 八种语言面具、五种潜台词模式 |
| **技术层** | 语言癖好、标点节奏、非语言信号 |
| **诊断层** | On-The-Nose 检测与修复 |

### 与其他技能的边界

| 相关技能 | 边界划分 |
|----------|----------|
| **show-dont-tell** | 展示元原则，本技能的"行为替代陈述"引用该技能 |
| **pov-system** | 客观视角更依赖潜台词，但视角规则由 pov-system 管理 |
| **psychology-craft** | 心理描写技法，本技能聚焦对话层面 |
| **expression-craft** | 微表情描写，本技能的"非语言信号"与其互补 |

## 一、理论基础

### 1.1 对话的三层结构

```
┌─────────────────────────────────────┐
│  表层 (Surface)                      │  ← 角色说出的话
├─────────────────────────────────────┤
│  潜层 (Subtext)                      │  ← 角色真正想表达的
├─────────────────────────────────────┤
│  深层 (Undercurrent)                 │  ← 角色自己都未必意识到的
└─────────────────────────────────────┘
```

**示例**：
| 层次 | 内容 |
|------|------|
| 表层 | "你今天回来得挺早的。" |
| 潜层 | "你是不是在外面有事瞒着我？" |
| 深层 | 对这段关系的不安全感 |

### 1.2 麦基的多重自我理论

人物拥有多个层面的自我，每一层都可能与其他层冲突：

| 自我层面 | 定义 | 示例 |
|----------|------|------|
| **社会自我** | 公共场合的面具 | 面对老板时顺从 |
| **个人自我** | 亲密关系中的表现 | 面对爱人时是控制狂 |
| **私密自我** | 独处时的真实状态 | 深深的自卑和恐惧 |
| **隐藏自我** | 自己都不知道的潜意识 | 渴望毁灭一切 |

### 1.3 潜台词的本质公式

```
潜台词 = 角色想要的 + 角色不能/不愿直说的原因
潜台词张力 = |外在表现| - |内在真实|
```

**不能直说的原因**：
- 社会规范禁止（不能当面骂人）
- 关系不允许（对上司的不满）
- 自我保护（暴露真心怕被伤害）
- 自己也没想清楚（潜意识层面）
- 策略考量（不想让对方知道真实意图）

## 二、八种语言面具

角色用这些"面具"包装真实意图：

| 面具 | 描述 | 示例 |
|------|------|------|
| 😊 **礼貌面具** | 用客套话包装真实情绪 | "您太客气了" = 别再送东西了 |
| 😏 **反讽面具** | 说反话表达真意 | "你可真行啊" = 你搞砸了 |
| 🤔 **转移面具** | 用无关话题回避核心 | 问A答B，顾左右而言他 |
| 😶 **沉默面具** | 用不说代替说 | 沉默、转身、中断话题 |
| 📋 **事务面具** | 用公事化语言隔离情感 | "我们保持职业关系吧" |
| 😤 **攻击面具** | 用攻击掩盖脆弱 | "我根本不在乎你" = 太在乎了 |
| 🎭 **表演面具** | 刻意展示虚假情绪 | 过度热情 = 内心抵触 |
| ❓ **疑问面具** | 用问题代替陈述 | "你觉得这样对吗" = 这样不对 |

### 面具运用示例

**场景**：妻子发现丈夫又加班到深夜

| 面具类型 | 台词 | 潜台词 |
|----------|------|--------|
| 礼貌面具 | "辛苦了，饭在锅里温着。" | 你心里还有这个家吗？ |
| 反讽面具 | "哟，今天回来算早的了。" | 你天天这么晚很过分 |
| 转移面具 | "你吃饭了吗？孩子今天又问你了。" | 回避正面冲突但施加压力 |
| 沉默面具 | [继续看电视，不说话] | 已经失望到不想沟通 |
| 攻击面具 | "跟你那工作过日子去吧。" | 我需要你，但你让我受伤 |

## 三、五种潜台词模式

| 模式 | 核心机制 | 适用场景 |
|------|----------|----------|
| **言不由衷** | 说与想相反 | 骄傲、防御、社交场合 |
| **答非所问** | 回避直接回应 | 不想面对、需要时间 |
| **话中有话** | 一语双关 | 试探、警告、暗示 |
| **以小见大** | 用小事说大事 | 真正问题太大不敢直面 |
| **借题发挥** | 用A的事发泄对B的不满 | 情绪积压、找不到出口 |

### 模式示例

**言不由衷**：
- "我没事。" → 我很不好
- "随便你。" → 我非常在意

**答非所问**：
- "你爱我吗？" → "我给你倒杯水。"

**话中有话**：
- "这咖啡有点苦。" → (在分手咖啡馆) 这段感情让我苦涩

**以小见大**：
- 为了谁洗碗吵架 → 实际是对家务分配的长期不满

## 四、语言癖好系统

不同的人有不同的说话方式，这直接反映性格和动机：

| 类型 | 特征 | 心理暗示 |
|------|------|----------|
| **连珠炮** | 语速极快，不带停顿 | 逃避自我、过度兴奋、不想被打断 |
| **龟速** | 语速极慢，多用省略号 | 迟钝、冷静、或掌权者的控制 |
| **娃娃音** | 成年人的尖锐声音 | 不安全感、拒绝长大 |
| **低音炮** | 声音浑厚深沉 | 权威感、压迫感 |
| **言辞谨慎者** | 不停斟酌用词 | 在意形象、想控制局势 |
| **一语中的者** | 只说"好""是" | 拒绝交流、冷淡、敌意 |
| **道歉者** | 总是说"对不起" | 羞愧、低自尊 |
| **大嗓门** | 全大写/加粗 | 想将意志强加于人 |

## 五、标点与节奏

对话的节奏就是语气的乐谱：

| 标点 | 效果 |
|------|------|
| **感叹号 (!)** | 不要滥用，轻声威胁更可怕 |
| **破折号 (—)** | 突然中断、话题转换、被打断 |
| **省略号 (…)** | 犹豫、思考、声音渐弱 |
| **斜体/加粗** | 改变重音，改变含义 |

**句式长短**：
- 紧张/急促 → 短句、单词、省略描写
- 放松/控制 → 长句、复杂修辞

**反差原则**：轻声细语的威胁比大吼大叫更可怕。

❌ **懒惰写法**：
> "'我恨不得杀了你！'她大吼道"

✅ **高级写法**：
> "她死死地盯着他，眼里充满仇恨和泪水。'我现在就可以杀了你。'她轻轻地说着。"

## 六、非语言信号

当情感过于强烈时，用身体反应替代语言：

| 情感 | 声音特征 | 动作特征 |
|------|----------|----------|
| **愤怒** | 变粗、尖叫、冷冰冰的低语 | 喷出口水、突然提高音量 |
| **恐惧** | 嘶哑、变尖、支吾、结巴 | 欲言又止、下巴颤动 |
| **悲伤** | 单调平淡、带着哭腔、泣不成声 | 长时间的沉默、深吸一口气后说话 |
| **爱** | 耳边低语、轻柔、幼稚口吻 | 靠近、触碰 |

> **引用**：详细的身体反应描写请参考 `show-dont-tell` 技能的"情感展示速查表"

## 七、On-The-Nose 检测与修复

### 什么是 On-The-Nose

**On-The-Nose（过于直白）**：角色直接说出自己的感受、意图或剧情信息，缺乏潜台词。

### 检测标准

| 问题类型 | 示例 | 诊断 |
|----------|------|------|
| **所想即所说** | "我很生气" | 过于直白 |
| **信息倾倒** | "正如你所知，鲍勃..." | 解释性对白 |
| **情绪播报** | "我现在非常紧张" | 自我播报 |
| **说教** | 直接说出主题或道德教训 | 缺乏艺术性 |

### 修复策略

#### 策略1：行为替代陈述
```
直白："我很害怕。"
修复：[她检查了第三遍门锁]
```

#### 策略2：对话间接化
```
直白："我爱你，不要离开我。"
修复："那件外套你带上吧。会冷的。"
```

#### 策略3：潜台词分层
```
直白："你让我很失望。"
修复："嗯，你做得很好。"[转身整理已经整齐的文件]
```

#### 策略4：沉默与停顿
```
直白："我很难过，说不出话来。"
修复：[沉默。窗外的雨打在玻璃上。]
```

#### 策略5：问题代替陈述
```
直白："我不信任你。"
修复："你那天晚上到底去哪了？"
```

## 八、双轨生成法

### CoT 双轨模式

```
┌─────────────────────────────────────────────────────────────┐
│ Track 1: 内心轨道（不输出）                                   │
├─────────────────────────────────────────────────────────────┤
│ 角色 A 想："我受够了，为什么他从来不关心我的感受..."            │
│ 角色 B 想："她又开始了，我工作已经够累了..."                   │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Track 2: 对白轨道（实际输出）                                 │
├─────────────────────────────────────────────────────────────┤
│ A："你今天回来挺早的。"                                       │
│ B："嗯，公司空调坏了。"                                       │
│ A："哦。饭在桌上。"                                          │
│ B："吃过了。"                                                │
│ [沉默]                                                      │
└─────────────────────────────────────────────────────────────┘
```

### 生成步骤

1. **设定**：明确每个角色的显性目标和隐性欲望
2. **内心轨道**：写出角色真正在想什么
3. **对白轨道**：选择合适的面具，生成实际台词
4. **打磨**：添加行为描写、停顿、非语言信号

## 九、对话质量评估

### 评分维度

```yaml
潜台词深度: [1-5]
  1: 完全直白
  5: 大师级潜台词

语言面具运用: [1-5]
  1: 无面具
  5: 面具本身揭示角色深层心理

行为-言语张力: [1-5]
  1: 完全一致
  5: 行为与言语形成复调

节奏与呼吸: [1-5]
  1: 机械问答
  5: 节奏本身是潜台词

解读空间: [1-5]
  1: 无需解读
  5: 可反复品味
```

## 十、检查清单

### 写作前
- [ ] 明确每个角色的显性目标
- [ ] 明确每个角色的隐性欲望
- [ ] 确定每个角色的"禁区"
- [ ] 设定对话的情感弧线

### 写作中
- [ ] 每句台词是否有潜台词
- [ ] 是否选择了合适的语言面具
- [ ] 是否有行为描写配合
- [ ] 是否有必要的沉默和停顿
- [ ] 对话节奏是否自然

### 写作后
- [ ] 是否有 On-The-Nose 台词
- [ ] 潜台词是否太隐晦或太明显
- [ ] 读者能否正确解读潜台词
- [ ] 对话是否推动了情节/关系
- [ ] 是否揭示了角色深层性格

## 十二、创作心法

> **"好的对白不是角色说了什么，而是角色没说什么。"**

> **"人们用语言来隐藏，而不是表达。"**

> **"当角色直接说出自己的感受时，你已经失去了读者一半的信任。"**

**记住**：
1. 真实生活中，人们很少直接表达情感
2. 沉默和行为往往比语言更诚实
3. 最好的潜台词让读者觉得"我听懂了"
4. 冲突不在于谁对谁错，而在于欲望的碰撞
5. 给读者留下解读的空间，是对读者的尊重
