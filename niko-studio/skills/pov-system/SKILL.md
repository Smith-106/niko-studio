# 叙事视角系统 (POV System)

## 概述

叙事视角决定了谁在讲故事、知道多少、与读者的距离感。本技能帮助作者选择最佳视角、设计切换规则、诊断一致性问题。

## 使用时机

- 新书开始前：选择最合适的叙事视角
- 写作过程中：检查视角是否一致
- 多视角作品：设计 POV 切换规则
- 改稿阶段：诊断视角相关问题

## 功能模块

```
pov-system
├── 1. 视角选择 - 根据故事需求选择最佳视角类型
├── 2. 切换策略 - 多视角作品的POV切换规则
└── 3. 一致性诊断 - 检测视角越界和混乱问题
```

## 模块一：视角选择

### 人称分类

| 人称 | 特点 | 适用场景 |
|------|------|----------|
| **第一人称** | "我"叙述，代入感强 | 心理深度、不可靠叙述、成长故事 |
| **第二人称** | "你"叙述，罕见但独特 | 互动小说、实验性作品 |
| **第三人称** | "他/她"叙述，灵活度高 | 大多数小说类型 |

### 视角深度（第三人称细分）

```
信息量
  ↑
  │  ┌─────────────────────────────────────┐
  │  │ 全知视角 (Omniscient)               │
  │  │ - 可进入任何角色内心                 │
  │  │ - 可评论、可预示                     │
  │  │ - 上帝视角，无限制                   │
  │  └─────────────────────────────────────┘
  │  ┌─────────────────────────────────────┐
  │  │ 有限全知 (Limited Omniscient)       │
  │  │ - 聚焦单一角色，但可切换             │
  │  │ - 每个场景一个POV角色                │
  │  │ - 现代小说最常用                     │
  │  └─────────────────────────────────────┘
  │  ┌─────────────────────────────────────┐
  │  │ 客观视角 (Objective)                │
  │  │ - 只描述外部行为                     │
  │  │ - 不进入任何人内心                   │
  │  │ - 冷硬派、戏剧化风格                 │
  │  └─────────────────────────────────────┘
  ↓
代入感
```

### 视角选择决策树

```
你的故事需要...

代入感 + 多角色内心 + 客观风格？
├─ 是 → 第三人称客观 + 行为暗示法（高级技巧）
└─ 否 → 继续...

读者深度代入主角？
├─ 是 → 第一人称 或 第三人称有限（单一POV）
└─ 否 → 继续...

展示多个角色的内心？
├─ 是 → 第三人称有限（多POV）或 全知
└─ 否 → 继续...

保持信息悬念？
├─ 是 → 第三人称客观 或 第一人称（不可靠叙述）
└─ 否 → 第三人称全知
```

### 高级技巧：行为暗示法

当需要同时满足 **代入感 + 多角色内心 + 客观风格** 时：

```
第三人称客观 + 行为暗示法

实现方式：
1. 不直接写"他感到愤怒"
2. 而是写"他的手指在桌下攥成拳头"

效果：
- 保持客观视角的冷静距离
- 读者通过行为"推断"内心 → 更强代入感
- 每个角色都可展示，无需进入内心
```

| 类型 | 写法 | 效果 |
|------|------|------|
| 直接内心 | "他感到一阵恐惧" | 告诉读者 |
| 行为暗示 | "他的喉结上下滚动，后退了半步" | 让读者感受 |

## 模块二：POV 切换策略

### 切换时机原则

| 原则 | 说明 | 违反后果 |
|------|------|----------|
| **场景边界** | 在场景或章节分隔处切换 | 读者混乱，不知跟谁 |
| **目的明确** | 每次切换都有叙事必要性 | 显得随意，削弱焦点 |
| **信息差异** | 切换后能获得新视角/信息 | 切换无意义，浪费篇幅 |
| **情绪衔接** | 考虑切换点的情绪过渡 | 情绪断裂，节奏破碎 |

### 切换模式

```
1. 章节轮换制
   第1章 [角色A] → 第2章 [角色B] → 第3章 [角色A]
   ✓ 清晰可预期
   ✗ 不够灵活

2. 需求驱动制
   根据情节需要选择最佳视角
   ✓ 灵活，信息最优
   ✗ 需要更高技巧

3. 主次分明制
   主角占70%+，配角偶尔插入
   ✓ 保持焦点，有变化
   ✗ 配角戏份受限

4. 平行交织制（多线叙事）
   A线 ──●────●────●────┐
   B线 ────●────●────●──┼→ 汇聚
   ✓ 适合群像/史诗
   ✗ 结构复杂，难驾驭
```

### 切换信号设计

| 信号类型 | 方法 | 示例 |
|----------|------|------|
| **位置标记** | 章节标题写明视角 | "第三章 · 林远" |
| **开场锚定** | 首句/首段点明角色 | "林远站在窗前..." |
| **语言风格** | 不同角色用不同语气 | 角色A简洁，角色B啰嗦 |
| **关注焦点** | 不同角色关注不同细节 | 医生注意伤口，士兵注意武器 |

### 切换禁区

| 禁忌 | 说明 |
|------|------|
| **段落内切换** | 同一段落跳到另一角色内心 |
| **无标记切换** | 没有任何信号就换人 |
| **悬念处切换** | 高潮时刻突然换视角（除非刻意留悬念） |
| **频繁切换** | 一章内切换3次以上 |

## 模块三：一致性诊断

### 常见视角问题

| 问题类型 | 表现 | 示例 |
|----------|------|------|
| **视角越界** | 进入非POV角色内心 | POV是A，却写"B心想..." |
| **信息越权** | POV角色不可能知道的信息 | 独处的A知道隔壁B在做什么 |
| **人称混乱** | 第一/第三人称混用 | "我看到他想..." |
| **距离漂移** | 时远时近，忽而深入忽而客观 | 同段落既写内心又写客观 |
| **全知泄露** | 有限视角中出现上帝评论 | "他不知道，这将是他最后一次..." |

### 诊断检查清单

```markdown
## POV 一致性检查

### 基础检查
- [ ] 每个场景是否有明确的POV角色？
- [ ] 是否只描写POV角色能感知的内容？
- [ ] 人称是否全篇一致？

### 内心描写检查
- [ ] 只有POV角色有直接内心描写？
- [ ] 其他角色内心是否通过行为暗示？
- [ ] 是否避免了"他知道她在想..."句式？

### 信息边界检查
- [ ] POV角色不在场时是否有场景描写？
- [ ] 是否使用了POV角色不知道的信息？
- [ ] 预示/伏笔是否超出POV知识范围？

### 切换检查（多POV）
- [ ] 切换是否发生在场景/章节边界？
- [ ] 切换是否有明确信号？
- [ ] 切换后是否快速锚定新POV？
```

### 修复策略

| 问题 | 修复方法 |
|------|----------|
| **视角越界** | 改为行为暗示，或添加"他猜测..."过渡 |
| **信息越权** | 删除或改为角色推测/后来得知 |
| **距离漂移** | 统一本场景的叙事距离 |
| **全知泄露** | 删除上帝视角评论，或改为角色预感 |

### 诊断输出格式

```markdown
## 视角诊断报告

### 检测到的问题
| 位置 | 问题类型 | 原文 | 建议 |
|------|----------|------|------|
| 第3章第2段 | 视角越界 | "她心里暗笑" | 改为"嘴角微微上扬" |
| ... | ... | ... | ... |

### 统计
- 视角越界：X 处
- 信息越权：X 处
- 距离漂移：X 处

### 整体评估
[视角一致性评分] + [主要问题总结]
```

## 与其他技能的协作

- **← show-dont-tell**：行为暗示法是"展示"的核心技巧
- **← psychology-craft**：心理描写受视角限制
- **← tension-scene**：视角选择影响张力呈现方式
- **→ subtext-dialogue**：客观视角需依赖潜台词传达内心
