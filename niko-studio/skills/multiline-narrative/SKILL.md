# 多线叙事系统 (Multiline Narrative)

## 概述

多线叙事是指故事同时追踪多条情节线，它们平行发展、交叉影响、最终汇聚。本技能帮助作者设计多线结构、规划编排策略、诊断交织问题。

## 使用时机

- 群像小说：多个主角各有故事线
- 史诗叙事：多条战线/势力并行
- 悬疑推理：多视角揭示不同线索
- 时空交错：过去与现在双线并进

## 功能模块

```
multiline-narrative
├── 1. 结构设计 - 确定线索数量、主次关系、汇聚模式
├── 2. 编排策略 - 章节内的线索切换与篇幅分配
└── 3. 交织诊断 - 检测线索失衡、断裂、汇聚问题
```

## 模块一：结构设计

### 线索关系模式

| 模式 | 结构 | 适用类型 |
|------|------|----------|
| **主副模式** | 1条主线 + 1-2条副线 | 大多数小说，保持焦点 |
| **平行模式** | 2-3条同等重要的线 | 群像、双主角、对照叙事 |
| **交织模式** | 多线频繁交叉影响 | 权谋、悬疑、多势力 |
| **收束模式** | 分散开局，逐步汇聚 | 史诗、末日、团队集结 |

### 结构可视化

```
主副模式：
主线 ════════════════════════════════►
副线 ────●────────●────────●─────────►
        ↑        ↑        ↑
      交叉点    交叉点    交叉点

平行模式：
A线 ════════●═══════════●════════════►
B线 ════════●═══════════●════════════►
            ↑           ↑
          交叉点      交叉点

交织模式：
A线 ══●════●═══●════●═══●════════════►
B线 ══●════●═══●════●═══●════════════►
C线 ══●════●═══●════●═══●════════════►
      ↑    ↑   ↑    ↑   ↑
     频繁交叉，相互影响

收束模式：
A线 ════════════════╗
B线 ════════════════╬════► 汇聚高潮
C线 ════════════════╝
```

### 线索数量建议

| 线索数 | 难度 | 建议 |
|--------|------|------|
| 2条 | ★☆☆ | 入门级，双主角或今昔对照 |
| 3条 | ★★☆ | 中等，经典三方博弈 |
| 4条+ | ★★★ | 高难度，需严密规划 |

**YAGNI 原则**：能用2条线讲清的故事，不要用3条。

### 结构选择决策树

```
你的故事需要...

有明确的单一主角？
├─ 是 → 主副模式（主角线 + 1-2条支线）
└─ 否 → 继续...

多个角色同等重要？
├─ 是 → 平行模式（2-3条均等线）
└─ 否 → 继续...

多方势力频繁互动？
├─ 是 → 交织模式（多线频繁交叉）
└─ 否 → 收束模式（分散开局，逐步汇聚）
```

## 模块二：编排策略

### 篇幅分配原则

| 模式 | 主线占比 | 副线占比 | 说明 |
|------|----------|----------|------|
| **主副模式** | 60-70% | 30-40% | 主线始终是焦点 |
| **平行模式** | 各40-50% | - | 基本均等，略有偏重 |
| **交织模式** | 按需分配 | 按需分配 | 根据情节重要性动态调整 |

### 切换节奏模式

```
1. 固定轮换
   A → B → A → B → A → B
   ✓ 节奏稳定，读者预期明确
   ✗ 机械感，缺乏灵活性

2. 张力驱动
   在一条线高潮/悬念处切换到另一条线
   ✓ 保持阅读欲望
   ✗ 可能让读者焦虑

3. 时间同步
   各线在同一时间点的不同视角
   ✓ 事件立体感强
   ✗ 需要精确的时间管理

4. 事件关联
   当A线事件影响到B线时切换
   ✓ 因果链清晰
   ✗ 需要精心设计交叉点
```

### 章节组织方式

| 方式 | 结构 | 适用场景 |
|------|------|----------|
| **独立章节** | 每章专注一条线 | 线索差异大、各自独立 |
| **分节混合** | 一章内多条线交替 | 线索紧密关联、节奏快 |
| **交叉收尾** | 章节主体一条线，结尾钩子切另一条 | 制造悬念、驱动阅读 |

### 切换信号设计

```markdown
## 线索切换信号

### 结构信号
- 章节标题标明线索："第五章 · 北境"
- 分节符号：***、───、◆◆◆
- 时间/地点标签：【三天前·京城】

### 内容信号
- 首句点明视角人物
- 环境描写暗示地点变化
- 独特的语言风格或叙事节奏
```

### 缺席管理

| 缺席时长 | 处理方式 |
|----------|----------|
| 1-2章 | 可接受，无需特殊处理 |
| 3-4章 | 回归时需简短回顾 |
| 5章+ | 危险！考虑插入简短场景或删除该线 |

## 模块三：汇聚策略与诊断

### 汇聚模式

| 模式 | 说明 | 示例 |
|------|------|------|
| **物理汇聚** | 角色在同一地点相遇 | 各路人马齐聚最终战场 |
| **因果汇聚** | 各线行动产生连锁反应 | A的决定影响B的命运 |
| **信息汇聚** | 各线拼凑出完整真相 | 悬疑中各视角揭示谜底 |
| **主题汇聚** | 各线印证同一主题 | 不同故事展现相同人性 |

### 汇聚节奏规划

```
分散度
  ↑
  │  ●─────────────────────●
  │   ╲                   ╱
  │    ╲    ●───────●    ╱
  │     ╲  ╱         ╲  ╱
  │      ╲╱           ╲╱
  │       ●           ●
  │                    ╲
  │                     ●──→ 完全汇聚
  └────────────────────────────→ 进度
  0%      25%    50%    75%   100%

典型节奏：
- 0-25%：各线独立建立
- 25-50%：首次交叉，暗示关联
- 50-75%：交叉加深，相互影响
- 75-100%：逐步汇聚，走向高潮
```

### 交织诊断问题类型

| 问题类型 | 表现 | 后果 |
|----------|------|------|
| **篇幅失衡** | 某条线占比过高/过低 | 读者遗忘副线角色 |
| **节奏断裂** | 某条线长时间不出现 | 情节连贯性受损 |
| **关联薄弱** | 各线缺乏交叉影响 | 像多个独立故事 |
| **汇聚突兀** | 最后强行凑到一起 | 巧合感、不可信 |
| **线索冗余** | 某条线可有可无 | 拖慢节奏、分散焦点 |

### 诊断检查清单

```markdown
## 多线叙事检查

### 结构检查
- [ ] 每条线是否有明确的目标和冲突？
- [ ] 主次关系是否清晰？
- [ ] 线索数量是否必要（YAGNI）？

### 编排检查
- [ ] 各线篇幅分配是否合理？
- [ ] 是否有线索超过3章未出现？
- [ ] 切换是否有明确信号？

### 关联检查
- [ ] 各线之间是否有因果联系？
- [ ] 交叉点是否推动了情节发展？
- [ ] 最终汇聚是否有充分铺垫？

### 阅读体验检查
- [ ] 切换时读者是否能快速定位？
- [ ] 各线是否都有独立吸引力？
- [ ] 整体是否形成有机整体？
```

### 诊断输出格式

```markdown
## 多线叙事诊断报告

### 线索概览
| 线索 | 篇幅占比 | 章节分布 | 状态 |
|------|----------|----------|------|
| A线（主角） | 55% | 均匀 | ✅ |
| B线（反派） | 30% | 均匀 | ✅ |
| C线（配角） | 15% | 集中后半 | ⚠️ 前期缺失 |

### 交叉点分析
| 位置 | 交叉类型 | 关联强度 |
|------|----------|----------|
| 第8章 | 信息传递 | ★★☆ |
| 第15章 | 物理相遇 | ★★★ |

### 检测到的问题
- [篇幅失衡]: C线前10章未出现
- [汇聚突兀]: 三线在最后1章才相遇

### 优化建议
1. 在第3-5章加入C线铺垫场景
2. 在第12章增加一次三线间接关联
```

## 与其他技能的协作

- **← pov-system**：多线叙事通常伴随多POV切换
- **← tension-arc**：各线需要独立的张力曲线
- **← tension-chapter**：章节内的多线编排影响节奏
- **→ foreshadowing-craft**：跨线伏笔增强关联感
