# 🔧 直白对白修复技能包 (On-The-Nose Fix)

> **核心理念**：当角色直接说出他们的感受时，戏剧性就消亡了。识别并转化直白对白，让言外之意成为真正的对话。

## 🚨 识别直白对白

### 定义

> 直白对白 (On-The-Nose Dialogue)：角色直接说出他们的感受、想法或意图，没有任何遮掩或潜台词。

### 危险信号清单

| 类型 | 示例 | 问题 |
|------|------|------|
| **情感陈述** | 「我现在很生气！」 | 直接告诉而非展示 |
| **动机解释** | 「我这么做是因为我爱你」 | 把潜台词说出来 |
| **关系定义** | 「你是我最好的朋友」 | 观众应该感受到，而非被告知 |
| **背景填充** | 「我们认识20年了，记得吗？」 | 硬塞信息 |
| **心理分析** | 「你这是在逃避问题」 | 角色变成心理医生 |

### 自动检测标记词

```python
ON_THE_NOSE_MARKERS = [
    # 情感直述
    "我很生气", "我很难过", "我很开心", "我很害怕",
    "我感到", "我觉得你",
    
    # 动机解释
    "因为我爱你", "因为我在乎", "这是因为",
    "我这么做是为了",
    
    # 关系陈述
    "你是我的", "我们是", "作为你的朋友",
    
    # 过度解释
    "你明白吗", "我的意思是", "让我解释",
    
    # 心理分析
    "你这是在", "你内心其实", "你潜意识里"
]
```

## 🔧 修复技法

### 技法一：行动替代

> 用行动展示情感，而非直接陈述。

```
❌ 直白版：
「我真的很担心你。」

✅ 修复版：
她第三次给他的杯子续满了茶，尽管他还没喝几口。
「路上慢点。」她说。
```

### 技法二：借物转移

> 把情感投射到物品或环境上。

```
❌ 直白版：
「我舍不得离开这里。」

✅ 修复版：
他的手指在门框上的刻痕上停留了一会儿——
那是儿子五岁时的身高。
「走吧。」他说，头也不回。
```

### 技法三：说反话

> 让角色说与内心相反的话。

```
❌ 直白版：
「我很想你。」

✅ 修复版：
「你怎么又来了？」她嘴上这么说，
却已经把他最喜欢的杯子放到了桌上。
```

### 技法四：转移话题

> 用回避暗示真正的情感。

```
❌ 直白版：
「我无法接受你要走。」

✅ 修复版：
「你晚饭想吃什么？」
「我...我刚说我要搬走。」
「我知道。晚饭想吃什么？」
```

### 技法五：身体语言

> 让身体说出嘴巴不愿说的话。

```
❌ 直白版：
「我对这件事感到很紧张。」

✅ 修复版：
他说「没什么大不了的」时，
手指一直在桌面上敲着，节奏越来越快。
```

## 🎬 修复示例库

### 示例1：愤怒

```
❌「我现在非常生气，你背叛了我！」

✅ 她把咖啡杯放下，动作很轻。
  太轻了。
 「你今晚不用回来吃饭了。」她说。
  然后开始收拾他放在玄关的鞋。
  一双一双，整整齐齐地装进袋子里。
```

### 示例2：爱意

```
❌「我爱你，我愿意为你做任何事。」

✅「你外套没拉拉链。」
   他走过来，动作比必要的慢，
   拉上拉链后，手指在那里停了一秒。
  「外面冷。」他说。
```

### 示例3：恐惧

```
❌「我很害怕，不知道未来会怎样。」

✅「这表不准了。」她说，又看了一眼手腕。
  「你刚看过。」
  「我知道。」她把表摘下来，又戴上。
  窗外的雨越下越大。
```

### 示例4：告别

```
❌「我会永远记得你的，再见。」

✅ 他在门口站了很久。
 「那个...」
 「嗯？」
 「没什么。」
  门关上了。
  走廊里他的脚步声停顿了一下，然后继续向前。
```
