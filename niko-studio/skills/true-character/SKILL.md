## 🔧 核心概念

### 人物塑造 vs 人物真相

| 维度 | 人物塑造 (Characterization) | 人物真相 (True Character) |
|------|---------------------------|-------------------------|
| 定义 | 外在可观察的特征 | 内在本质 |
| 展示方式 | 描述、对话、习惯 | 两难抉择下的行动 |
| 例子 | 他穿着名牌西装 | 他为了救陌生人放弃了面试机会 |
| 作用 | 建立第一印象 | 揭示灵魂深处 |

## 🎬 压力揭示法

### 原理

> 只有在压力下做出的选择，才能揭示一个人真正是谁。

```
公式：
人物真相 = 两难选择 + 不可逆行动 + 代价

示例：
张三面对选择：举报贪污的恩师 vs 保持沉默获得提拔
他选择了举报 → 揭示：正义感 > 个人利益
他选择了沉默 → 揭示：实用主义 > 道德原则
```

### 压力等级设计

| 等级 | 赌注 | 示例 |
|------|------|------|
| Lv.1 | 社会形象 | 说实话丢面子 vs 撒谎保全面子 |
| Lv.2 | 关系 | 告诉朋友真相伤害他 vs 隐瞒保护他 |
| Lv.3 | 事业 | 坚持原则失去工作 vs 妥协保住工作 |
| Lv.4 | 生命 | 冒生命危险救人 vs 保全自己 |
| Lv.5 | 灵魂 | 违背毕生信念 vs 让挚爱之人死去 |

## 🔧 两难选择设计技巧

### 技巧一：善善冲突

> 两个选项都是"好的"，但只能选一个。

```
示例：
医生只有一份血清，两个病人都是孩子
选择A = 救自己的孩子（亲情）
选择B = 救陌生人的孩子（公正）

→ 无论选什么都会揭示人物真相
```

### 技巧二：恶恶冲突

> 两个选项都有严重后果，必须选一个。

```
示例：
囚徒困境变体：
选择A = 背叛同伴，自己获释，他坐10年牢
选择B = 保持沉默，两人都坐5年牢

→ 选择揭示：自私程度 vs 忠诚程度
```

### 技巧三：时间压力

> 不给思考时间，逼出本能反应。

```
示例：
大楼着火，只有30秒：
- 带走笔记本电脑（里面是十年的工作）
- 还是带走相册（里面是已故母亲的照片）

→ 本能选择揭示：事业 vs 情感
```

## 🎯 两难选择检查清单

- [ ] 两个选项是否都有合理的吸引力？
- [ ] 是否有足够的压力（时间/赌注）？
- [ ] 选择是否不可逆？
- [ ] 选择是否有实际代价？
- [ ] 选择是否揭示了角色的核心价值观？
- [ ] 读者是否能在选择中感受到角色的灵魂？

## 🎬 大师案例

### 《蝙蝠侠：黑暗骑士》- 双船困境

```
设置：两艘船，一艘载满罪犯，一艘载满普通市民
规则：12点前炸掉对方，否则两艘都炸

揭示的人物真相：
- 普通市民投票炸掉罪犯船（多数人的自私）
- 但没有人愿意按下按钮（行动 vs 想法的差距）
- 罪犯把引爆器扔出窗外（出乎意料的救赎）

→ 真正的人物真相只在行动中显现
```
