# 👁️ Show-Don't-Tell 展示不告知大师

> **Skill ID**: `show-dont-tell`
> **Version**: 2.0 (Merged)
> **Category**: core/technique
> **Triggers**: `展示`, `show`, `告知`, `tell`, `描写`, `表达`, `情感展示`, `行为描写`

---

## 一、核心理念

### 1.1 本质定义

**Tell（告知）**：直接陈述信息、情感或判断
**Show（展示）**：通过具体细节让读者自己感知和推断

```
Tell: 她很生气。
Show: 她的指节攥得发白，茶杯在桌上震出一圈涟漪。
```

### 1.2 为什么要 Show

| 维度 | Tell 的问题 | Show 的优势 |
|------|------------|------------|
| 参与感 | 读者被动接收 | 读者主动推理 |
| 可信度 | 作者说什么是什么 | 证据自己说话 |
| 记忆度 | 抽象概念易忘 | 具体画面难忘 |
| 情感共鸣 | 隔靴搔痒 | 感同身受 |

### 1.3 黄金法则

```
展示程度 ∝ 情感重要性
```

- **核心情感/转折点**：必须充分展示
- **过渡段落**：可适当告知以控制节奏
- **背景信息**：告知往往更高效

## 二、四维展示法

### 2.1 维度一：身体反应

将抽象情感转化为可观察的生理现象：

| 情感 | 身体反应示例 |
|------|-------------|
| 恐惧 | 瞳孔放大、汗毛竖立、呼吸急促、肌肉僵硬 |
| 愤怒 | 血管暴起、牙关紧咬、拳头攥紧、脸颊发烫 |
| 悲伤 | 喉咙哽咽、视线模糊、肩膀塌陷、动作迟缓 |
| 喜悦 | 嘴角上扬、眼睛发亮、步伐轻快、声音上扬 |
| 紧张 | 手指绞动、频繁吞咽、坐立不安、声音发颤 |
| 尴尬 | 目光躲闪、耳根发红、手足无措、语无伦次 |
| 厌恶 | 皱眉、后退半步、嘴角下撇、呼吸变浅 |
| 惊讶 | 动作停顿、嘴巴微张、眨眼频率变化 |

**身体反应三层次**：
```
L1 面部微表情：眉毛、眼睛、嘴唇、脸颊
L2 肢体语言：手势、姿态、步态、距离
L3 生理反应：心跳、呼吸、出汗、颤抖
```

### 2.2 维度二：行为动作

通过具体行为暴露内心状态：

| 情感 | 行为展示 |
|------|----------|
| 焦虑 | 反复检查手机、整理已经整齐的物品、无意识抖腿 |
| 愧疚 | 避开眼神、主动承担不属于自己的事、过度补偿 |
| 嫉妒 | 贬低对方成就、过分关注对方动态、酸溜溜的"恭喜" |
| 思念 | 抚摸旧物、去曾经一起去的地方、对着照片发呆 |
| 隐藏 | 说话时摸鼻子、过度解释、转移话题 |

**行为描写原则**：
1. **具体化**：不是"收拾东西"，而是"把铅笔按颜色排成一排"
2. **异常化**：打破日常行为模式更能说明问题
3. **持续性**：重要情感通过多个行为叠加展示

### 2.3 维度三：环境投射

用环境反映内心状态或烘托情感：

| 情感 | 环境投射 |
|------|----------|
| 孤独 | 空旷的房间、回声、被遗忘的角落 |
| 压抑 | 低矮的天花板、昏暗的光线、密闭空间 |
| 希望 | 破云而出的阳光、春天的萌芽、远方的灯火 |
| 危险 | 暴风雨前的宁静、影子的移动、不协调的声音 |
| 甜蜜 | 温暖的色调、柔和的光线、花香/咖啡香 |

**环境描写技法**：
```
选择性注意：角色会注意到与其情绪相关的环境细节
情绪滤镜：同一环境在不同情绪下呈现不同面貌
对比反衬：快乐中的阴影，悲伤中的阳光
```

### 2.4 维度四：对话潜台词

通过对话暗示而非明说：

| Tell 对话 | Show 对话 |
|-----------|-----------|
| "我很担心你" | "你...吃饭了吗？" |
| "我还爱着你" | "那件毛衣我还留着，你要是冷的话..." |
| "我不原谅你" | "没事，都过去了。" [转身收拾行李] |
| "我嫉妒你的成功" | "真厉害啊，运气真好。" |

**对话展示技巧**：
1. **说反话**：嘴上说没事，行动表明有事
2. **答非所问**：回避直接回应，说明心理抗拒
3. **过度反应**：对小事反应过激，说明压抑太久
4. **沉默**：不说比说更有力量

## 三、高级展示技法

### 3.1 内心独白拉长术

将瞬间的情感反应拉长为可感知的体验：

**Tell版**：
> 他感到心碎。

**Show版（内心独白拉长）**：
> 那四个字从她嘴里说出来的时候，他觉得世界好像安静了一秒。不对，是他自己安静了。周围的声音还在——冰箱的嗡嗡声，楼下的汽车喇叭，窗台上风铃的叮当——但这些声音好像隔着一层玻璃。他听见自己说"哦"，声音平稳得像是别人在说话。直到走出咖啡馆，冷风扑面，他才发现自己的手一直在发抖。

### 3.2 陌生化技法

用新鲜的角度描述熟悉的事物：

| 常规描述 | 陌生化描述 |
|----------|------------|
| 她哭了 | 有什么温热的东西滑过脸颊，带着咸味 |
| 天很冷 | 呼出的气变成白色，很快消失，像一个来不及许的愿望 |
| 他老了 | 镜子里的那个人，什么时候开始有了父亲的眼袋 |

### 3.3 对比展示法

通过前后/内外对比强化展示效果：

**时间对比**：
> 三年前她会为一只流浪猫哭半天。现在，站在父亲的病床前，她的眼睛干涩得发疼。

**表里对比**：
> "我没事。"她笑着说，手却把杯子握得太紧，咖啡洒了一点在桌上。

**期待与现实对比**：
> 他演练了一百遍见面要说的话。真见到她时，只挤出一句："你头发剪短了。"

### 3.4 留白艺术

有时不写比写更有力：

```
Tell: 他们分手了，他很痛苦。

Show (留白): 
    他删掉了她的所有照片。
    只保留了一张——两个人的背影，看不清脸。
    [新段落，三个月后]
    那张照片还在手机里。他没有打开过，但也没有删除。
```

## 四、Tell→Show 转换引擎

### 4.1 转换公式

```
Tell句子 → 拆解为具体元素 → 选择展示维度 → 构建具体场景
```

### 4.2 转换示例

| Tell | 拆解 | 维度选择 | Show |
|------|------|----------|------|
| 他很紧张 | 紧张=担心失败+身体反应 | 身体+行为 | 他的领带打了三次，第三次比前两次更歪 |
| 她爱上了他 | 爱=关注+期待+小心翼翼 | 行为+对话 | 她开始研究足球规则，即使她分不清越位和角球的区别 |
| 这个地方很危险 | 危险=异常+威胁信号 | 环境 | 酒吧里所有人都在看他们，但没有人说话。角落的点唱机卡在同一句歌词上 |
| 他们关系恶化了 | 恶化=距离感+敌意 | 行为+对话 | "盐。"她说。他把盐递过去，两人的手指小心翼翼地避开彼此 |
| 她压力很大 | 压力=身心疲惫+失控感 | 身体+行为 | 冰箱里的外卖盒已经叠到第三层了。她又点开手机，又放下。又点开 |

### 4.3 深度转换模板

```yaml
输入:
  tell_sentence: "[原始告知句]"

分析:
  核心情感: [识别要展示的情感]
  触发情境: [什么导致了这种情感]
  角色特征: [这个角色会如何表达]

展示选择:
  主维度: [身体/行为/环境/对话]
  辅维度: [可选第二维度]
  
输出:
  show_paragraph: |
    [展示版本的段落]
```

## 六、Tell 词汇黑名单

### 6.1 情感状态词（高危）

```
生气、愤怒、悲伤、快乐、恐惧、紧张、焦虑、兴奋
孤独、无聊、沮丧、绝望、满足、平静、困惑、惊讶
嫉妒、羞耻、愧疚、骄傲、轻蔑、厌恶、感激、爱
```

**处理方式**：检测到这些词时，触发展示转换

### 6.2 判断性形容词（中危）

```
好/坏、美/丑、善良/邪恶、聪明/愚蠢、勇敢/懦弱
重要、有趣、危险、奇怪、完美、糟糕、特别
```

**处理方式**：用具体事例或行为来证明

### 6.3 程度副词（低危但警示）

```
非常、极其、十分、相当、格外、无比、特别
```

**处理方式**：这些词往往是偷懒的信号，考虑用细节替代

### 6.4 偷懒动词（警示）

```
觉得、感到、意识到、知道、明白、发现
似乎、好像、仿佛（过度使用时）
```

**处理方式**：直接展示感知到的内容

## 七、检测与评分系统

### 7.1 Show 密度检测

```python
# 伪代码逻辑
def calculate_show_density(paragraph):
    tell_patterns = [情感词, 判断词, 程度副词]
    show_patterns = [动作动词, 感官细节, 具体名词]
    
    tell_count = count_matches(paragraph, tell_patterns)
    show_count = count_matches(paragraph, show_patterns)
    
    density = show_count / (tell_count + show_count)
    return density

# 评分标准
# > 0.8: 优秀，沉浸感强
# 0.6-0.8: 良好，基本达标
# 0.4-0.6: 一般，需要改进
# < 0.4: 较差，大量告知
```

### 7.2 场景评分卡

```yaml
评分维度:
  感官细节: [1-5]  # 视/听/触/嗅/味
  身体反应: [1-5]  # 生理状态描写
  行为描写: [1-5]  # 具体动作
  环境融合: [1-5]  # 环境与情感呼应
  对话暗示: [1-5]  # 潜台词运用

总分: /25
评级:
  20-25: 沉浸级
  15-19: 合格级
  10-14: 需改进
  <10: 需重写
```

## 八、常见错误与修复

### 8.1 错误类型

| 错误 | 示例 | 问题 | 修复 |
|------|------|------|------|
| 直接贴标签 | "他是个善良的人" | 读者无感 | 用行为证明善良 |
| 情感词堆砌 | "她感到悲伤、绝望、无助" | 空洞无力 | 选一种，深度展示 |
| 过度解释 | "她皱眉，显然很生气" | 不信任读者 | 删除"显然很生气" |
| 感官缺失 | 只有视觉描写 | 不够立体 | 加入其他感官 |
| 滥用比喻 | "像xxx一样悲伤" | 还是在Tell | 直接展示悲伤的样子 |

### 8.2 快速修复检查清单

写完一个场景后：
- [ ] 搜索情感状态词，逐个转换
- [ ] 检查是否有五感细节
- [ ] 确认角色有具体动作
- [ ] 对话是否有潜台词
- [ ] 环境是否与情感呼应
- [ ] 删除多余的解释性语句

## 十、实战练习

### 练习1：单句转换

将以下 Tell 句子转换为 Show 段落：

| Tell | 你的 Show |
|------|-----------|
| 他很孤独 | _________ |
| 她爱上了他 | _________ |
| 这顿饭很难吃 | _________ |
| 他害怕失去她 | _________ |
| 天气很热 | _________ |

### 练习2：段落改写

**原文 (Tell版)**：
> 李明非常紧张。今天是他的面试，这份工作对他很重要。他知道如果失败了，就再也没有机会了。他感到压力很大，焦虑得睡不着觉。

**改写要求**：
- 删除所有情感状态词
- 用身体反应展示紧张
- 用行为展示重要性
- 用环境烘托压力

### 练习3：对话改写

**原文 (Tell版)**：
> "我真的很爱你，"他深情地说。"失去你我会很痛苦。请不要离开我。"

**改写要求**：
- 不直接说"爱"
- 通过行为和潜台词展示感情
- 保留情感强度

- [ ] 是否有过度展示导致拖沓

## 十二、创作心法

> **"不要告诉读者月光明亮，给他们看碎玻璃上的闪光。"**
> —— 契诃夫

> **"展示不是堆砌细节，而是选择正确的细节。"**

> **"最好的展示让读者觉得是自己发现了真相，而不是作者告诉他的。"**

**记住**：
1. Show 是默认选择，Tell 是有意识的策略
2. 重要的情感值得多花笔墨展示
3. 信任读者的智慧，他们能读懂你的暗示
4. 具体的细节比抽象的形容更有力量
5. 有时一个动作胜过千言万语
