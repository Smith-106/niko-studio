## 核心定义

动作描写不仅指激烈的打斗或追逐，更是指通过人物的具体行为来**展示（Show）**其性格、情绪，并推动情节发展的核心技术。好的动作描写是**"感官的容器"**——让读者不仅"看到"画面，还能在肌肉和神经中"感觉"到故事的发生。

---

## 第一原则：展示，不要说明 (Show, Don't Tell)

### 1.1 感官细节替代叙述

| ❌ 说明式写法 | ✅ 展示式写法 |
|-------------|-------------|
| 他走进了花园 | 风吹过冬青的感觉、茉莉花的香气扑面而来 |
| 他很害怕 | 马克瞪大眼睛，嘴巴张得老大，试图呼吸却吸不到气 |
| 她跑得很快 | 她的脚掌拍打地面，肺部像要炸开 |

### 1.2 客观关联物（T.S.艾略特）

要引起读者的情感共鸣，必须详细描述出**引起该情感的具体行为或事件**，而不是直接谈论情感本身。

---

## 核心技法

### 技法一：慢动作拉长法 (Stretch)

在关键冲突或危机时刻，通过"慢动作"手法拉长紧张感。

**操作方法**：像电影慢放一样，将瞬间动作拆解，交替使用：
- **动作** → **内心戏** → **对话** → **叙述**

**示例**：
```
❌ 他攻击了她。

✅ 玛莉退后一步，撞上茶几（动作）。
   花瓶掉在地上碎了（描述）。
   "别害怕。"男子说（对话）。
   他怎么进来的？门明明锁着（内心戏）。
```

**心理时间拉长**：在危机时刻，感官会变得敏锐。描写具体细节（雾的湿度、背包在背上的跳动、心跳声），让读者感受到时间的停滞。

### 技法二：节奏控制法

| 效果 | 技巧 | 适用场景 |
|------|------|---------|
| **加速** | 短句、短段落、省略主语 | 激烈动作、紧迫感 |
| **减速** | 长句、环境描写、内心独白 | 强调动作重量、让读者喘息 |
| **编织** | 将对话编入动作中 | 增加立体感和真实感 |

**编织示例**：
```
❌ "你为什么骗我？"她问。他没回答。

✅ 她用扳手拧下螺丝，金属刮擦声尖锐刺耳。
   "你为什么骗我？"
   他把沾满机油的手在抹布上擦了擦，依然没抬头。
```

### 技法三：动作即人物 (Character is Action)

动作是揭示人物性格最诚实的方式：

| 维度 | 描写要点 |
|------|---------|
| **独特习惯** | 不同性格的人动作习惯不同（昂首阔步 vs 拖着脚走） |
| **压力下的选择** | 人物在压力下的行动揭示"人物真相" |
| **非语言信号** | 外部信号（握拳、咬唇）+ 内部感觉（胃痛、心跳加速） |

**示例**：
```
一个精于算计的人喝咖啡：
→ 他用小指轻轻托起杯底，啜了一小口，然后把杯子精确地放回杯垫中央。

一个大大咧咧的人喝咖啡：
→ 他一口气灌下半杯，咖啡从嘴角流下来，他用袖子一抹。
```

## 剧本动作描写规范

| 规范 | 说明 |
|------|------|
| **现在时态** | 必须使用现在时态描写正在发生的事 |
| **视觉化** | 只描写摄影机能拍到的东西 |
| **简练** | 段落不超过4行，留出阅读"留白" |
| **少用指导** | 避免微观管理演员的每个微小动作 |
| **以动作开场** | 场景开始时让角色处于某种行动中 |

---

## 常见误区与修正

| 误区 | 修正 |
|------|------|
| 陈词滥调："眼珠骨碌碌地转"、"下巴掉在地上" | 使用新鲜、具体的生理细节 |
| 无意义动作：点烟、喝水不服务于情节 | 每个动作必须揭示人物状态或推动潜台词 |
| 只有动作没有反应 | 遵循"行动—反应—继续行动"的逻辑 |
| 动作与对话割裂 | 将对话编入行动中（边修车边吵架） |

## AI提示链：动作场景生成

### Step 1: 场景定锚
```
请描述一个[紧张/激烈/温馨]的动作场景。
要求：
1. 明确场景的核心冲突是什么
2. 主角的目标是什么
3. 阻碍主角的障碍是什么
```

### Step 2: 慢动作拆解
```
请将上述场景的关键3秒钟用"慢动作"技法展开：
1. 交替使用：动作描写 → 感官细节 → 内心戏 → 对话
2. 调动至少3种感官（视觉、听觉、触觉、嗅觉）
3. 描写至少一个生理反应（心跳、出汗、肌肉紧绷）
```

### Step 3: 节奏校准
```
请检查上述段落的节奏：
1. 紧张处是否使用了短句？
2. 是否有"喘息点"让读者放松？
3. 动作与对话是否有机编织？
请根据需要调整句子长短。
```

### Step 4: 人物真相检验
```
请回答：
1. 通过这个动作场景，读者能了解主角什么性格特点？
2. 如果删除所有对话，仅凭动作能否理解人物状态？
3. 有没有"说一套做一套"的反差设计？
```

## 情感-动作速查表

| 情感 | 外部动作信号 | 内部生理反应 |
|------|-------------|-------------|
| **恐惧** | 后退、僵住、双手发抖 | 胃部翻腾、喉咙发紧 |
| **愤怒** | 握拳、咬牙、脖子青筋暴起 | 血液沸腾、太阳穴突突跳 |
| **紧张** | 用指关节敲桌、来回踱步 | 手心出汗、心跳加速 |
| **悲伤** | 动作迟缓、低垂双肩 | 胸口发闷、四肢无力 |
| **喜悦** | 跳跃、拥抱、手舞足蹈 | 胸腔扩张、身体发热 |
