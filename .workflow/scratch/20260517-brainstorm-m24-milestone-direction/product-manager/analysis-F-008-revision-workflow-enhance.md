# F-008: Intelligent Revision Workflow Enhancement — Product Analysis

## User Value Proposition

基于 M23 读者体验模型（reader-state + hook/cliffhanger 分析），为作者提供定向修订建议、修订前后对比分析、迭代修订追踪与效果量化。将"发现问题"的能力延伸为"指导解决问题"的完整闭环。

**核心价值**: 从分析到行动的闭环 + 修订效果可量化 + 写作质量持续提升

## Priority Justification

### Impact vs Effort Matrix

| 维度 | 评估 |
|------|------|
| 用户影响 | High（直接改善写作质量） |
| 市场影响 | Medium（竞品有类似但不如深度） |
| 技术复杂度 | Very High（需完整修订循环） |
| 实施工作量 | Very High（UI + 引擎 + 数据） |
| 风险 | Medium（依赖多个前置项） |

**综合优先级**: P3 — 用户价值高但实施复杂度过高，SHOULD 延至 M25 作为重点方向。

## Success Metrics

| 指标 | 目标值 | 测量方式 |
|------|--------|----------|
| 修订建议采纳率 | >= 40% | 用户行为统计 |
| 修订后质量提升 | 读者体验评分提升 >= 15% | M23 模型重新评估 |
| 修订循环完成率 | >= 70% 用户完成至少 1 轮 | 流程统计 |
| 修订耗时 | 比无指导修订减少 30% | 时间对比 |
| 用户满意度 | >= 4.2/5.0 | 应用内反馈 |

## User Stories

### US-001: 作为作者，我希望系统告诉我具体哪里需要修订以及如何修订
**动机**: M23 能发现问题（如"第 3 章张力不足"），但不提供修订方向
**验收**: 针对每个问题点提供 2-3 个具体修订建议，附带示例和原理说明

### US-002: 作为作者，我希望看到修订前后的质量对比
**动机**: 修订后不确定是否真的改善了，需要客观量化反馈
**验收**: 修订后自动重新评估，展示各维度评分变化（提升/持平/下降）

### US-003: 作为作者，我希望追踪多轮修订的累积效果
**动机**: 长篇小说修订是迭代过程，需要看到整体进步轨迹
**验收**: 提供修订历史时间线，展示各轮修订的质量变化趋势

## Acceptance Criteria

### 完整版（建议 M25）

1. MUST 基于 M23 读者体验模型生成定向修订建议
2. 每个修订建议 MUST 包含：问题描述、修订方向、具体示例
3. MUST 支持修订前后的自动对比评估
4. MUST 追踪修订历史，展示质量变化趋势
5. SHOULD 支持"接受/拒绝/稍后"的修订建议管理
6. SHOULD 支持批量修订模式（按维度批量处理）
7. MUST NOT 自动修改用户文本（仅建议，不代写）

### M24 可选预研（MAY）

- 修订建议生成算法的原型验证
- 修订前后对比的数据模型设计
- UI 交互原型（低保真）

## Dependencies and Sequencing

### 前置依赖（硬性）
- F-005 Craft-Catalog 外置 MUST 完成（修订建议需要外置知识数据）
- F-006 Workflow-Engine 重构 MUST 完成（修订工作流需要 TaskHandler 扩展点）
- M23 读者体验模型（已完成）

### 前置依赖（软性）
- F-002 组件拆分 SHOULD 完成（修订 UI 需要可扩展的面板架构）
- F-003 类型安全 SHOULD 完成（revisionOrchestrator 类型加固）

### 后续影响
- 为写作知识个性化提供"弱项识别"数据源
- 为写作会话智能提供"修订模式"的行为基线

### 建议排期
- **M25 Phase 1**（非 M24）
- 预估工时：15-20 天（完整版）
- M24 中 MAY 投入 2-3 天做预研和原型

### 延期理由

1. **依赖链过长**: 需要 F-005 + F-006 都完成后才能开始，在 M24 时间框架内风险过高
2. **用户反馈不足**: M23 读者模型刚上线，需要收集用户实际使用模式后再设计修订流程
3. **MVP 难以定义**: 不同于 F-007 可以"只做时间轴"，修订工作流需要完整循环才有价值
4. **与 F-007 互斥**: M24 只能容纳 1 个新功能方向，F-007 的 ROI 更高
