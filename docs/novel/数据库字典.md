# 小说数据库字典（Obsidian）

> 目标：统一字段命名与类型，确保 Dataview / Timeline / Agent 自动化可稳定工作。

## 1. 全局命名规范

- 字段命名：统一使用 `snake_case`
- 布尔字段：`is_*` / `has_*`
- 列表字段：使用数组（YAML list）
- 时间字段：统一 `YYYY-MM-DD`
- 枚举字段：只使用本文档定义的枚举值

## 2. 通用字段（所有实体建议）

| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| id | string | 是 | 全局唯一ID | `chr-ailin` |
| title | string | 是 | 条目标题 | `艾琳·陈` |
| entity_type | enum | 是 | 实体类型 | `character` |
| status | enum | 是 | 状态 | `active` |
| tags | string[] | 否 | 标签 | `["主角", "研究者"]` |
| created_at | date | 否 | 创建日期 | `2026-02-21` |
| updated_at | date | 否 | 更新日期 | `2026-02-21` |

### 2.1 entity_type 枚举
- `character`
- `chapter`
- `foreshadowing`
- `location`
- `item`
- `timeline_event`

### 2.2 status 枚举（通用）
- `active`
- `draft`
- `archived`

## 3. 人物（character）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| name | string | 是 | 人物名 |
| aliases | string[] | 否 | 别名 |
| role_type | enum | 是 | `protagonist / supporting / antagonist` |
| goals | string[] | 否 | 当前目标 |
| conflicts | string[] | 否 | 关键冲突 |
| relationships | string[] | 否 | 关系引用ID |
| first_appearance_chapter | number | 否 | 初登场章节 |
| current_state | string | 否 | 当前状态摘要 |

---

## 4. 章节（chapter）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| chapter_number | number | 是 | 章节号 |
| chapter_title | string | 是 | 章节标题 |
| volume | string | 否 | 卷标识 |
| pov_character | string | 否 | POV 人物ID |
| timeline_date | date | 否 | 章节主日期 |
| location_ids | string[] | 否 | 涉及地点ID |
| character_ids | string[] | 否 | 涉及人物ID |
| key_events | string[] | 否 | 本章关键事件 |
| word_count | number | 否 | 字数 |
| draft_version | string | 否 | 草稿版本 |
| chapter_status | enum | 是 | `planned / drafting / revising / final` |

---

## 5. 伏笔（foreshadowing）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| foreshadowing_title | string | 是 | 伏笔标题 |
| importance | enum | 是 | `high / medium / low` |
| foreshadowing_status | enum | 是 | `planted / advanced / resolved` |
| planted_chapter | number | 是 | 埋设章节 |
| target_resolved_chapter | number | 否 | 目标回收章节 |
| actual_resolved_chapter | number | 否 | 实际回收章节 |
| related_character_ids | string[] | 否 | 关联人物 |
| related_event_ids | string[] | 否 | 关联事件 |

---

## 6. 地点（location）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| location_name | string | 是 | 地点名 |
| region | string | 否 | 所属区域 |
| location_type | enum | 否 | `city / town / facility / wilderness / other` |
| climate | string | 否 | 气候 |
| rule_notes | string | 否 | 与世界观规则关联 |

---

## 7. 时间线事件（timeline_event）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| event_name | string | 是 | 事件名 |
| event_date | date | 是 | 事件日期 |
| chapter_number | number | 否 | 对应章节 |
| related_character_ids | string[] | 否 | 关联人物 |
| related_location_ids | string[] | 否 | 关联地点 |
| cause_ids | string[] | 否 | 前置事件 |
| effect_ids | string[] | 否 | 后续事件 |

---

## 8. 字段统一映射（兼容旧字段）

| 旧字段 | 标准字段 |
|---|---|
| `wordcount` | `word_count` |
| `chapter` | `chapter_number` |
| `title`(章节) | `chapter_title` |
| `characters` | `character_ids` |
| `location` | `location_ids`（单值也用数组） |
| `plant_chapter` | `planted_chapter` |
| `harvest_chapter` | `actual_resolved_chapter` |
| `foreshadowing_planted` | `planted_chapter` |
| `foreshadowing_resolved` | `actual_resolved_chapter` |

---

## 9. MVP最小字段集（建议）

- 人物：`id, name, role_type, current_state, first_appearance_chapter, status`
- 章节：`id, chapter_number, chapter_title, chapter_status, pov_character, word_count, timeline_date`
- 伏笔：`id, foreshadowing_title, foreshadowing_status, planted_chapter, target_resolved_chapter, importance`

> 先保证最小字段集稳定，再逐步扩展高级字段。
