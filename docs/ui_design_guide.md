## 一、技术选型建议

### 方案对比

| 方案 | 优势 | 劣势 | 推荐场景 |
|------|------|------|---------|
| **Streamlit** (现有) | 快速原型、Python 生态 | 定制受限、性能一般 | MVP 验证 ✅ |
| **纯 Web (CCW 风格)** | 完全定制、性能好 | 开发成本高 | 生产环境 ⭐⭐⭐ |
| **Electron (AionUi 风格)** | 离线可用、原生体验 | 资源占用大 | 桌面应用 ⭐⭐ |
| **Next.js + TailwindCSS** | 现代栈、组件丰富 | 需要 Node.js | 云端部署 ⭐⭐ |

### 推荐方案：渐进式迁移

```
Phase 1 (当前): Streamlit 原型 → 功能验证
         ↓
Phase 2 (3个月): 纯 Web SPA  → 核心功能
         ↓
Phase 3 (6个月): Electron 封装 → 桌面版（可选）
```

**核心技术栈**（参考 CCW）：
- **前端**: HTML5 + Vanilla JS（模块化）+ CSS Modules
- **后端**: Python FastAPI（已有 LangGraph 集成）
- **实时通信**: WebSocket（会话进度推送）
- **数据可视化**: Plotly.js / D3.js（LOCK 评分、8维度雷达图）

### 2.2 侧边栏导航（分组设计）

#### 📂 项目组
- **概览**：统计卡片（总会话、完成章节、平均质量分）
- **文件浏览器**：`.writing/` 目录树查看
- **会话历史**：最近 10 个会话快速切换
- **任务看板**：场景卡片 Kanban（PENDING | WRITING | DONE）

#### 💬 对话流组
- **活跃会话**：当前正在进行的对话
- **协作面板**：Agent 对话历史（参考 Streamlit 原型）
- **HITL 面板**：人工介入（反馈提交、批准）

#### 🧠 记忆组
- **核心记忆列表**：CMEM-* 记录（参考 CCW Core Memory）
- **会话聚类**：自动/手动聚类管理
- **知识图谱**：实体关系可视化（Cytoscape.js）
- **引用网络**：SHA256 引用链（OpenKL Citations）

#### 📊 分析组
- **质量仪表板**：LOCK + 8维度趋势图
- **进度热图**：章节完成度日历视图
- **性能监控**：LLM 调用耗时/成本

#### 🔧 设置组
- **模型配置**：切换 Gemini/Claude/Qwen
- **工作流参数**：L1-L5 级别配置
- **技能管理**：自定义 Skills（参考 AionUi）

### 4.1 实时反馈机制

**参考**: CCW WebSocket + Streamlit Status

```python
# FastAPI 后端 WebSocket 推送
@app.websocket("/ws")
async def websocket_endpoint(websocket: WebSocket):
    await websocket.accept()
    while True:
        # 工作流进度推送
        await websocket.send_json({
            "event": "WORKFLOW_PROGRESS",
            "data": {
                "agent": "Writer",
                "status": "generating",
                "progress": 45,  # 0-100
                "message": "生成第2段场景描写..."
            }
        })
```

**前端实时更新**：
```javascript
// WebSocket 连接
const ws = new WebSocket('ws://localhost:8000/ws');

ws.onmessage = (event) => {
  const { event: type, data } = JSON.parse(event.data);
  
  if (type === 'WORKFLOW_PROGRESS') {
    updateProgressBar(data.agent, data.progress);
    showToast(data.message);
  }
};
```
