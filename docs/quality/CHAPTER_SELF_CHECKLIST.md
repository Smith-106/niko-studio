# 每章自检清单（写前 / 写中 / 写后）

> 用途：用于章节级快速自检，确保每章在进入终稿前达到可发布质量。

## 一、写前（Before Writing）

- [ ] 本章目标一句话清晰可述（角色要做什么、为什么现在做）。
- [ ] 本章主冲突明确（阻力来源、代价边界）。
- [ ] 本章主情节原型已标注（参考 Tobias 20 Master Plots，建议 1 个主原型）。
- [ ] POV 与叙事视角已固定。
- [ ] 角色状态已对齐上一章结尾。
- [ ] 本章关联伏笔列表已准备（新增/推进/回收）。
- [ ] 世界观约束已确认（本章涉及规则、禁忌、边界）。

## 二、写中（During Writing）

- [ ] 开场 10%-15% 内建立问题或悬念。
- [ ] 中段至少有一次冲突升级。
- [ ] 每个关键场景具备“目标-阻力-结果”。
- [ ] 对话承担功能（推进情节/揭示人物/制造冲突）。
- [ ] 关键事件具备因果链，不是跳跃推进。
- [ ] 感官细节服务于情绪与行动，不是堆砌描述。

## 三、写后（After Writing）

- [ ] 结尾具备牵引力（新问题、代价升级或不可逆后果）。
- [ ] 人物行为未脱离既有人设（无 OOC）。
- [ ] 伏笔状态已更新到记录文件。
- [ ] 文风、节奏、视角保持一致。
- [ ] 本章综合质量达到章级阈值（`>= 99%`）。
- [ ] 若未达标，已生成修订任务并记录到证据目录。

## 四、未通过处理

- [ ] 连续 2 轮修订仍未达标 -> 触发“强制重写”。
- [ ] 出现关键设定冲突 -> 先修规则一致性，再做文笔润色。
- [ ] 主线偏航 -> 先回到章节目标与因果链重构。

## 五、留档位置

- 修订案例：`.workflow/evidence/quality/YYYY-MM-DD-revision-case.md`
- 周度统计：`.workflow/evidence/weekly/YYYY-Www-review.md`
