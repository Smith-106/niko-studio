# 长篇小说质量检查清单（Novel Quality Checklist）

> 用途：把“写作方法”落到可执行检查，服务于 `docs/PDD.md` 第 19/22 章与质量证据留档。

## 1. 使用规则

- 适用对象：章节草稿、章节修订稿、卷级串联检查。
- 使用时机：写前规划、写中巡检、写后终审。
- 判定原则：任一 `Critical` 未清零，不得进入终稿。

## 2. 写前检查（输入完整性）

- [ ] 章节目标明确（冲突推进点 + 结尾钩子）。
- [ ] POV 角色与本章状态已确定。
- [ ] 关键角色状态已从上一章同步。
- [ ] 伏笔快照已更新（新增/推进/回收）。
- [ ] 世界观约束摘要齐备（本章相关规则）。

## 3. 结构检查（LOCK + 三幕双门）

### 3.1 LOCK 基线

- [ ] `Lead`：主角当前欲望/恐惧在本章有体现。
- [ ] `Objective`：本章短期目标可被一句话描述。
- [ ] `Conflict`：存在可观察阻力，不是无摩擦推进。
- [ ] `Knockout`：结尾形成后续章节牵引力。

### 3.2 三幕双门（章级）

- [ ] 开场 10%-15% 建立局面与问题。
- [ ] 中段出现升级点，冲突强度提高。
- [ ] 结尾出现不可逆后果或新问题。
- [ ] 本章“门 1”（进入冲突）已落地。
- [ ] 本章“门 2”（代价升级）有明确提示或兑现。

## 4. 叙事质量检查（与 PDD 第 19 章一致）

- [ ] 人物一致性：动机、能力边界、行为风格无明显漂移。
- [ ] 情节因果：关键事件具备前因后果链。
- [ ] 节奏控制：铺垫/冲突/转折/回收比例合理。
- [ ] 伏笔回收：本章涉及伏笔状态更新准确。
- [ ] 世界观一致性：规则与设定无冲突。
- [ ] 文风稳定性：语气、句式密度、叙述视角稳定。

## 5. 场景与对话检查

- [ ] 每个关键场景有“目标-阻力-结果”。
- [ ] 对话推动信息或关系变化，不是填充。
- [ ] 感官细节支撑情绪，不是孤立堆砌。
- [ ] 关键转折前有足够铺垫。

## 6. 修订触发与放行规则

### 6.1 必须返工（任一命中）

- [ ] 同一章节连续 2 轮修订后仍未达阈值。
- [ ] 出现关键角色 OOC（Out of Character）。
- [ ] 主线偏航且无法通过局部修订纠正。
- [ ] 关键伏笔在计划窗口内无法回收。

### 6.2 放行条件（章级）

- [ ] 综合质量达标（章级通过标准：`>= 99%`）。
- [ ] 无 `Critical` 冲突。
- [ ] 上述清单中所有必选项均已勾选。

## 7. 证据留档

- [ ] 修订前后对比已记录：`.workflow/evidence/quality/YYYY-MM-DD-revision-case.md`
- [ ] 周度质量统计已同步：`.workflow/evidence/weekly/YYYY-Www-review.md`
- [ ] 如涉及流程失败，已补失败记录：`.workflow/evidence/e2e/YYYY-MM-DD-failures.md`

## 8. 经典情节原型对照（Tobias 20 Master Plots）

> 用途：在“章节目标一句话”与“卷级推进目标”阶段，快速校验当前章节属于哪类主驱动情节，避免主线偏航。

- Quest（探寻）
- Adventure（冒险）
- Pursuit（追逐）
- Rescue（营救）
- Escape（逃脱）
- Revenge（复仇）
- The Riddle（谜题）
- Rivalry（竞争）
- Underdog（弱者逆袭）
- Temptation（诱惑）
- Metamorphosis（蜕变）
- Transformation（转化）
- Maturation（成熟）
- Love（爱情）
- Forbidden Love（禁忌之爱）
- Sacrifice（牺牲）
- Discovery（发现）
- Wretched Excess（过度/沉溺）
- Ascension（上升）
- Descension（下降）

### 8.1 章级快速判定

- [ ] 本章已明确主情节原型（至少 1 个，最多 2 个）。
- [ ] 本章冲突与结尾钩子与该原型一致（非“挂名原型”）。
- [ ] 若跨原型切换，已在章末给出可追踪的因果桥接。

### 8.2 情节原型 -> 章级冲突模板（每型 3 项）

#### Quest（探寻）
- [ ] 本章存在明确“要找到什么”的目标物/答案。
- [ ] 路径阻力来自距离、规则或信息缺失。
- [ ] 结尾推进到下一段路程而非原地循环。

#### Adventure（冒险）
- [ ] 主角主动进入未知场域或高风险事件。
- [ ] 本章出现至少一次环境性威胁（地形/系统/外力）。
- [ ] 结尾带来新奇发现或更大风险承诺。

#### Pursuit（追逐）
- [ ] 本章存在“追者-被追者”双向动态。
- [ ] 冲突核心是时间差与路径选择。
- [ ] 结尾必须改变双方距离或位置优势。

#### Rescue（营救）
- [ ] 本章明确“被救对象”和其危险时限。
- [ ] 阻力来自防线、误导或营救代价。
- [ ] 结尾让营救成功率产生可见变化（升或降）。

#### Escape（逃脱）
- [ ] 本章明确“封闭系统”与逃脱出口条件。
- [ ] 冲突核心是资源不足或通道受限。
- [ ] 结尾必须改变自由度（更接近脱困或更被困）。

#### Revenge（复仇）
- [ ] 本章明确复仇对象及其伤害来源。
- [ ] 主角行动包含筹备、试探或打击之一。
- [ ] 结尾体现复仇代价（道德/关系/风险）升级。

#### The Riddle（谜题）
- [ ] 本章抛出可验证的问题而非纯悬浮悬念。
- [ ] 关键线索可被读者回溯定位。
- [ ] 结尾要么给出阶段答案，要么提出更高阶问题。

#### Rivalry（竞争）
- [ ] 本章明确对手双方共享同一目标赛道。
- [ ] 冲突表现为能力、资源或规则博弈。
- [ ] 结尾必须刷新排名、声望或筹码差。

#### Underdog（弱者逆袭）
- [ ] 本章先建立主角劣势（能力/地位/资源）。
- [ ] 冲突中出现一次“小胜”或关键生存动作。
- [ ] 结尾保留差距但确认逆袭可能性上升。

#### Temptation（诱惑）
- [ ] 本章出现具体诱惑对象（权力/欲望/捷径）。
- [ ] 主角经历可见的价值冲突与拉扯。
- [ ] 结尾给出一次选择并显示其后果方向。

#### Metamorphosis（蜕变）
- [ ] 本章出现身份或状态突变触发点。
- [ ] 冲突体现“旧自我”与“新状态”不兼容。
- [ ] 结尾确认蜕变不可逆或代价不可撤销。

#### Transformation（转化）
- [ ] 本章推进长期性内在转变（信念/人格）。
- [ ] 冲突来自旧习惯对新认知的反扑。
- [ ] 结尾可观察到行为层面的新选择。

#### Maturation（成熟）
- [ ] 本章主角面对责任而非仅满足情绪。
- [ ] 冲突要求其放弃幼态反应模式。
- [ ] 结尾呈现更稳定的判断或承担动作。

#### Love（爱情）
- [ ] 本章推进双方关系状态（接近/疏离/确认）。
- [ ] 冲突来自误解、差异或外部压力。
- [ ] 结尾给出关系层面的新承诺或新裂痕。

#### Forbidden Love（禁忌之爱）
- [ ] 本章明确禁忌来源（制度/伦理/阵营）。
- [ ] 冲突体现“相爱收益 < 现实代价”的压力。
- [ ] 结尾升级曝光风险或牺牲成本。

#### Sacrifice（牺牲）
- [ ] 本章明确“放弃什么”与“换取什么”。
- [ ] 冲突要求在两种损失中做选择。
- [ ] 结尾确认牺牲已发生且无法完全回收。

#### Discovery（发现）
- [ ] 本章出现改变认知框架的新信息。
- [ ] 冲突来自旧认知与新事实的矛盾。
- [ ] 结尾推动目标、关系或策略重设。

#### Wretched Excess（过度/沉溺）
- [ ] 本章展示角色在欲望中的失衡行为。
- [ ] 冲突体现“短期快感 vs 长期损耗”。
- [ ] 结尾出现明确损失信号（健康/关系/事业）。

#### Ascension（上升）
- [ ] 本章体现角色地位或能力的上升路径。
- [ ] 冲突来自更高层级的门槛与审视。
- [ ] 结尾获得阶段性晋级并引入更高风险。

#### Descension（下降）
- [ ] 本章体现角色控制力或地位下滑。
- [ ] 冲突来自错误决策累积或外部反噬。
- [ ] 结尾确认下滑趋势并压缩回旋空间。

## 9. 冲突与悬念专项模板（Bell）

> 用途：强化“每章都有冲突 + 每段有张力 + 结尾有悬念”，用于修正“信息齐全但不好读”的平直章节。

### 9.1 冲突密度（章级）

- [ ] 本章主冲突清晰，且至少发生 1 次升级。
- [ ] 关键场景中存在对抗性目标（双方不能同时达成）。
- [ ] 中段不存在连续“无阻力叙述”超过 2 个关键段落。

### 9.2 悬念推进（章级）

- [ ] 开场 10%-15% 内抛出问题或不确定性。
- [ ] 本章至少设置 1 个“未立即回答”的信息点。
- [ ] 结尾保留读者继续阅读动机（未决风险/未决关系/未决真相）。

### 9.3 对话与内心冲突

- [ ] 关键对话包含立场碰撞，而非纯信息交换。
- [ ] 主角至少出现 1 次“外部目标 vs 内在需求”的拉扯。
- [ ] 重要选择前有犹豫成本，选择后有后果回声。

### 9.4 写后返工触发（冲突/悬念维度）

- [ ] 若读后可删去任一关键场景且主线无影响 -> 判定冲突强度不足，需返工。
- [ ] 若章末已把所有问题一次性解释完 -> 判定悬念断流，需返工。
- [ ] 若对话可整体替换为旁白且信息损失很小 -> 判定对话冲突不足，需返工。

## 10. 情节-人物平衡专项模板（Gerke）

> 用途：避免“情节很猛但人物像工具人”或“人物很细但剧情不前进”，确保章节同时推进事件线与人物弧线。

### 10.1 双线推进一致性（章级）

- [ ] 本章至少有 1 个外部事件推进（情节线）。
- [ ] 本章至少有 1 个内部状态变化（人物线）。
- [ ] 两条变化存在因果关联，而非并排发生。

### 10.2 人物驱动校验

- [ ] 关键行动由角色动机触发，而非作者强推情节。
- [ ] 角色选择符合其当前能力边界与价值取向。
- [ ] 若角色做反常选择，文本已给出足够触发依据。

### 10.3 情节压力校验

- [ ] 本章压力来源具体可见（人/制度/环境/时间）。
- [ ] 压力迫使角色做出取舍，而非仅表达情绪。
- [ ] 结尾压力状态发生变化（升级、转向或兑现）。

### 10.4 成长轨迹校验

- [ ] 本章选择让角色更接近或更远离其核心目标。
- [ ] 本章至少暴露 1 个角色缺陷或执念成本。
- [ ] 本章结果在后续章节可追溯（非一次性情绪波动）。

### 10.5 写后返工触发（情节-人物失衡）

- [ ] 若只剩事件清单、几乎看不到角色决策逻辑 -> 判定“人物失真”，需返工。
- [ ] 若只有心理描写、主线目标几乎未前进 -> 判定“情节失速”，需返工。
- [ ] 若关键转折与角色既有弧线冲突且无铺垫 -> 判定“弧线断裂”，需返工。

## 11. 提纲骨架专项模板（Weiland）

> 用途：把章节写作与全书提纲绑定，避免“单章好看但全局散架”。

### 11.1 骨架锚点一致性（章级）

- [ ] 本章可明确归位到提纲骨架节点（开端/推进/转折/收束）。
- [ ] 本章目标与卷级目标存在直接映射关系。
- [ ] 本章结尾为下一锚点提供了必要前置条件。

### 11.2 节点功能完整性

- [ ] 本章承担的骨架功能是单一主功能（不同时承担过多结构任务）。
- [ ] 本章关键事件可回答“为什么必须发生在这里”。
- [ ] 若删除本章，提纲链路将出现可识别断点。

### 11.3 因果桥接质量

- [ ] 本章开场承接上一章结果，而非重置状态。
- [ ] 本章中段冲突升级与上一节点埋设保持因果连续。
- [ ] 本章结尾后果可直接触发下一章行动，不依赖硬切跳转。

### 11.4 提纲偏航预警

- [ ] 本章新增设定未破坏既有主线顺序与优先级。
- [ ] 若出现“临场灵感支线”，已限制篇幅且不抢主线节奏。
- [ ] 章节完成后，提纲状态已同步更新（新增/改动/删除节点）。

### 11.5 写后返工触发（骨架维度）

- [ ] 若本章在提纲中找不到明确节点归属 -> 判定“骨架脱锚”，需返工。
- [ ] 若本章主要信息与上一章重复 -> 判定“结构空转”，需返工。
- [ ] 若本章结尾无法自然导向下一章行动 -> 判定“桥接断裂”，需返工。

## 12. 剧本游戏叙事专项模板（Interactive / LARP）

> 用途：适配“多角色、可互动、信息分发”的叙事场景，防止单线小说思路直接套用导致可玩性不足。

### 12.1 角色目标与博弈

- [ ] 每个关键角色有可执行的当章目标（非抽象口号）。
- [ ] 角色目标之间存在冲突或竞争关系（可形成博弈）。
- [ ] 角色行动空间清晰，不因剧本硬控而失去选择感。

### 12.2 信息分发与线索公平性

- [ ] 关键线索有分层投放路径（公开/私密/条件触发）。
- [ ] 关键真相不是“只有作者知道、玩家无法推理”。
- [ ] 信息差能制造张力，但不会导致无解死局。

### 12.3 场景节拍与推进

- [ ] 每个关键场景都有触发条件与退出条件。
- [ ] 场景推进依赖角色行动结果，而非纯时间推进。
- [ ] 结尾阶段能收束主要冲突并保留复盘空间。

### 12.4 主持与执行可落地性（DM/主持人视角）

- [ ] 关键规则与判定口径可被主持人稳定执行。
- [ ] 高风险分支存在兜底机制（防卡死、防提前崩盘）。
- [ ] 关键道具/证据/身份信息有明确交付时机与责任人。

### 12.5 写后返工触发（互动叙事维度）

- [ ] 若多数角色“无事可做”或目标同质化 -> 判定“角色玩法失衡”，需返工。
- [ ] 若核心谜团必须靠作者口述揭晓 -> 判定“线索链断裂”，需返工。
- [ ] 若任一关键分支失败即全局停摆 -> 判定“流程脆弱”，需返工。

## 13. 非虚构叙事专项模板（Harvard Narrative Nonfiction）

> 用途：用于事实类写作（案例、纪实、品牌叙事、长文文案），在“真实可信”前提下保持故事张力。

### 13.1 事实锚点与叙事边界

- [ ] 本章核心事实可追溯（来源、时间、人物、地点至少两项可核）。
- [ ] 推断与事实已分层标注，不用主观判断冒充证据。
- [ ] 关键结论能回链到具体材料，而非只靠作者立场。

### 13.2 场景化表达

- [ ] 至少有 1 个可视化场景（人物动作 + 环境细节 + 时间点）。
- [ ] 场景服务论点推进，而非为“文艺感”堆砌。
- [ ] 场景中的信息能被后文复用，构成论证链条。

### 13.3 人物与声音

- [ ] 关键人物有明确角色功能（证人/当事人/对立方/解释者）。
- [ ] 引语承担信息增量，不重复作者旁白。
- [ ] 人物声音保持一致，不被作者口吻覆盖。

### 13.4 结构与节奏（非虚构）

- [ ] 开场在 10%-15% 内提出核心问题或冲突。
- [ ] 中段至少出现一次认知升级（新证据/新视角/反证）。
- [ ] 结尾给出“可执行结论”或“未决问题”，而非空泛抒情收束。

### 13.5 写后返工触发（非虚构维度）

- [ ] 若关键观点缺可核事实支撑 -> 判定“论证失真”，需返工。
- [ ] 若全文只有观点复述、缺少场景与人物承载 -> 判定“叙事失载”，需返工。
- [ ] 若结尾只重复开头观点、无新增信息或行动建议 -> 判定“收束失效”，需返工。

## 14. 人物原型系统专项模板（Schmidt 45 Archetypes）

> 用途：在角色设计与章节推进中引入“原型一致性 + 反原型张力”，避免角色扁平化与行为失真。

### 14.1 角色原型标注

- [ ] 主角与关键配角均已标注主原型（每人 1 个主原型）。
- [ ] 若角色跨原型发展，已定义阶段切换条件。
- [ ] 原型标注已同步到角色卡与章节计划。

### 14.2 原型一致性校验

- [ ] 角色关键选择与其核心驱动力一致。
- [ ] 角色弱点与盲点在章节中可观察到。
- [ ] 角色能力边界未被无铺垫突破。

### 14.3 反原型张力校验

- [ ] 至少设置 1 组价值观冲突角色（主原型 vs 反原型）。
- [ ] 冲突结果推动人物关系或剧情结构变化。
- [ ] 对立角色不被工具化，具备自洽行动逻辑。

### 14.4 成长与阴影弧线

- [ ] 本章有角色“光明面”或“阴影面”被触发的证据。
- [ ] 角色变化由事件压力驱动，而非作者声明式转变。
- [ ] 章节结尾保留下一步人物弧线牵引点。

### 14.5 写后返工触发（人物原型维度）

- [ ] 若角色行为无法回链到既定原型驱动力 -> 判定“原型失配”，需返工。
- [ ] 若对立角色仅承担阻碍功能、缺乏自我目标 -> 判定“反派工具化”，需返工。
- [ ] 若关键人物在多章内无任何弧线变化 -> 判定“人物停滞”，需返工。

## 15. 写作工艺与修订纪律专项模板（Stephen King）

> 用途：强化“先写完、再修订、持续阅读与稳定产出”的执行纪律，把灵感型写作收敛为可复用流程。

### 15.1 草稿完成纪律

- [ ] 本章先完成可读草稿，再进入细节优化（禁止边写边无限打磨）。
- [ ] 草稿阶段优先保证因果与动作连续，不追求句句精雕。
- [ ] 若章节未收束到可评审状态，不提前进入终稿判定。

### 15.2 修订聚焦规则

- [ ] 每轮修订有单一主目标（结构/人物/语言三选一优先）。
- [ ] 删除冗余段落优先于新增修辞（先减法后加法）。
- [ ] 修订后可明确回答“本轮具体变好了什么”。

### 15.3 语言与可读性

- [ ] 句式服务叙事清晰度，不以炫技替代信息传递。
- [ ] 对话保留角色个体声音，避免同口吻化。
- [ ] 描写与细节用于推进情绪/行动，不堆砌辞藻。

### 15.4 输入与产出习惯

- [ ] 本周有稳定阅读输入（同类作品或高质量文本）。
- [ ] 本周有稳定写作输出（章节/片段/修订记录）。
- [ ] 输入内容可映射到本项目的具体改进动作。

### 15.5 写后返工触发（工艺维度）

- [ ] 若长期停留在局部抛光、章节始终不完稿 -> 判定“完稿失序”，需返工流程。
- [ ] 若修订轮次增加但问题类型不收敛 -> 判定“修订失焦”，需重设修订目标。
- [ ] 若语言华丽但情节/人物推进不足 -> 判定“文采替代叙事”，需返工。

## 16. 对白行为与台词功能专项模板（McKee）

> 用途：将对白视为“行动”，而非信息填充；用于提升场景张力、角色区分度与潜台词深度。

### 16.1 对白功能校验

- [ ] 关键对白至少承担一项功能（推进情节/改变关系/暴露动机）。
- [ ] 对白后场景状态发生变化（立场、风险、信息、行动之一）。
- [ ] 不存在大段“说了很多但局面不变”的空转对白。

### 16.2 潜台词与意图冲突

- [ ] 角色“说的内容”与“真实意图”存在可识别张力。
- [ ] 关键冲突不全部靠直白解释完成。
- [ ] 对白中至少有一次策略性表达（试探、回避、误导、压迫）。

### 16.3 角色声音区分度

- [ ] 不同角色在词汇、节奏、句长上可辨识。
- [ ] 高压场景下角色语言符合其身份与心理状态。
- [ ] 角色口吻在跨章节保持稳定，不随作者旁白漂移。

### 16.4 场景对白节拍

- [ ] 对白与动作交替组织，避免连续纯台词堆积。
- [ ] 关键台词前后有足够行为支点（动作/沉默/转移）。
- [ ] 结尾台词形成牵引力（新目标/新风险/新误解）。

### 16.5 写后返工触发（对白维度）

- [ ] 若删除关键对白后剧情几乎不变 -> 判定“对白无功能”，需返工。
- [ ] 若角色对白可互换而不影响识别 -> 判定“角色失声”，需返工。
- [ ] 若冲突场景主要靠解释而非行为推进 -> 判定“台词替代戏剧”，需返工。

## 17. 剧本叙事引擎专项模板（Tobin）

> 用途：把故事拆成可执行的核心要素（前提/缺陷/欲望/阻力/转折/改变），用于提升剧本与小说章节的结构稳定性。

### 17.1 核心前提清晰度

- [ ] 本章冲突可用一句“人物 + 目标 + 阻力”描述。
- [ ] 本章前提与全书主命题一致，不发生主题偏航。
- [ ] 本章关键事件服务该前提，而非并列插入。

### 17.2 角色缺陷与驱动力

- [ ] 主角存在可识别缺陷（认知/性格/关系/能力之一）。
- [ ] 缺陷在本章具体影响其决策与代价。
- [ ] 本章推进了“修复缺陷”或“被缺陷反噬”的路径。

### 17.3 欲望与行动链

- [ ] 本章主角欲望具体可执行（不是抽象愿望）。
- [ ] 欲望驱动至少一个关键行动节点。
- [ ] 行动结果反向改变下一步策略或风险。

### 17.4 阻力与反作用力

- [ ] 本章存在明确反作用力（对手/制度/环境/时间）。
- [ ] 阻力强度随场景推进发生升级或变体。
- [ ] 结尾保留未完成压力，形成下一章牵引。

### 17.5 改变与兑现

- [ ] 本章末角色状态相较开场有可观察变化。
- [ ] 变化不是口头声明，而是行为/关系/结果层兑现。
- [ ] 变化与前文铺垫形成因果闭环。

### 17.6 写后返工触发（叙事引擎维度）

- [ ] 若本章无法明确“欲望-行动-结果”链路 -> 判定“引擎失火”，需返工。
- [ ] 若角色缺陷从头到尾未影响任何关键决策 -> 判定“缺陷失效”，需返工。
- [ ] 若结尾无状态变化且无后续牵引 -> 判定“章节无推进”，需返工。

## 18. 高张力小说专项模板（Frey Advanced）

> 用途：提升故事爆发力与戏剧能量，避免“结构完整但读感平”的中低张力问题。

### 18.1 戏剧张力曲线

- [ ] 本章至少有一次显著压力抬升（风险、代价或时间压缩）。
- [ ] 冲突强度在中后段高于开场，不出现强度塌陷。
- [ ] 结尾形成新的不稳定状态，而非回到安全平衡。

### 18.2 角色承压与选择

- [ ] 主角在本章面对“不可兼得”的选择场景。
- [ ] 关键选择带来可见损失或长期后果。
- [ ] 角色在压力下的行为符合其性格与缺陷逻辑。

### 18.3 场景爆点设计

- [ ] 本章存在至少 1 个记忆点场景（转折/揭示/反击/崩溃）。
- [ ] 爆点前有有效铺垫，爆点后有后果兑现。
- [ ] 爆点不是凭空反转，而由既有因果链触发。

### 18.4 节奏与信息控制

- [ ] 信息释放遵循“先问题后答案”的顺序。
- [ ] 高张力段落中避免无关解释性插入。
- [ ] 关键信息揭示后推动下一轮冲突升级。

### 18.5 写后返工触发（张力维度）

- [ ] 若本章关键场景可整体降级且阅读体验无变化 -> 判定“张力不足”，需返工。
- [ ] 若冲突频发但无代价兑现 -> 判定“空转刺激”，需返工。
- [ ] 若高潮段仅靠信息堆砌、缺少行动后果 -> 判定“伪高潮”，需返工。

## 19. 起稿驱动与练习化推进专项模板（Ellis / 《开始写吧！》）

> 用途：把“写不出来”问题转成可执行动作，用短练习与场景化起稿降低启动门槛，并确保练习结果真正回流到章节质量。

### 19.1 起稿触发与行动化

- [ ] 本章在开写前已设定一个可执行触发点（场景问题/角色冲突/一句钩子）。
- [ ] 起稿目标可在 15-30 分钟内落地，不以“等灵感”为前提。
- [ ] 起稿段落直接进入行动或矛盾，不用大段背景铺陈替代推进。

### 19.2 场景种子与扩写路径

- [ ] 本章至少有 1 个“场景种子”（人物 + 目标 + 阻力）可独立成段。
- [ ] 场景扩写遵循“目标 -> 受阻 -> 结果变化”链路，而非信息堆叠。
- [ ] 结尾保留下一步可执行写作入口（下一场景问题/下一冲突动作）。

### 19.3 观察采样与细节落地

- [ ] 本章至少落地 1 组可感知细节（视觉/听觉/触觉/气味/动作反馈）。
- [ ] 细节用于支持角色状态或冲突压力，不做孤立装饰。
- [ ] 抽象情绪至少有 1 处被具体行为或环境细节承载。

### 19.4 练习闭环与版本推进

- [ ] 本章写作至少执行 1 次定向练习（如开头重写/对白重写/视角重写）并保留结果。
- [ ] 练习后有明确取舍结论（保留/替换/废弃），避免“练了但没进入正文”。
- [ ] 练习产物已回流到章节版本，且能说明具体改善点。

### 19.5 写后返工触发（起稿与练习维度）

- [ ] 若连续多次起稿仍停留在背景说明、缺少行动冲突 -> 判定“起稿失效”，需返工。
- [ ] 若练习产物与正文脱节、无法支持章节目标 -> 判定“练习失联”，需返工。
- [ ] 若文本仅完成字数推进、未形成场景状态变化 -> 判定“机械完稿”，需返工。

## 20. 剧本问题清单化修复专项模板（Ecks / 《你的剧本逊毙了》）

> 用途：将“剧本常见失败点”转为可定位、可修复、可复核的清单，按思路/人物/结构/场景/对白分层排错，避免泛化修改。

### 20.1 问题定位与优先级

- [ ] 本章已明确 1-3 个最高优先级问题点（不是笼统“再润色”）。
- [ ] 每个问题都有可观察症状（读感卡顿、冲突不足、角色失真等）。
- [ ] 每个问题绑定单一修复目标，避免一轮修订同时处理过多维度。

### 20.2 人物与目标强度校验

- [ ] 主角目标在本章可被一句话复述，且具备失败代价。
- [ ] 关键阻力来源明确（人物/制度/时间/环境），不是空泛“困难很多”。
- [ ] 反向力量（对手/反目标）在本章有实质动作，而非仅被口头提及。

### 20.3 结构与推进压强校验

- [ ] 本章存在可识别推进节点（触发 -> 升级 -> 后果），无中段塌陷。
- [ ] 场景顺序服务主冲突推进，删除任一关键场景会造成链路断点。
- [ ] 章节结尾形成明确下一步压力（时间逼近/风险扩大/关系恶化）。

### 20.4 场景与对白功能校验

- [ ] 每个关键场景都能回答“这场戏改变了什么”。
- [ ] 对白承担行动功能（试探/施压/反击/误导），不是解释性填充。
- [ ] 角色台词可区分，且在高压场景下语言选择与身份一致。

### 20.5 迭代修订与成稿门禁

- [ ] 修订记录包含“问题 -> 对策 -> 结果”闭环，可追溯到具体段落。
- [ ] 本轮至少移除 1 处无效段落/无功能对白，体现减法修订。
- [ ] 成稿前完成一次“整章问题复检”，确认高优先级问题已清零。

### 20.6 写后返工触发（剧本诊断维度）

- [ ] 若问题描述停留在抽象评价、无法定位到具体段落 -> 判定“诊断失焦”，需返工。
- [ ] 若修订动作很多但主问题未改善 -> 判定“对策失效”，需返工。
- [ ] 若章节可读性提升但主冲突与角色目标仍不清晰 -> 判定“表层优化”，需返工。

## 21. 同故事多讲法变体专项模板（Matt Madden / 《一个故事的99种讲法》）

> 用途：在不丢失核心事件链的前提下，通过视角、时序、叙述距离、表达介质等变体重构同一故事，提升叙事弹性与表达精度。

### 21.1 核心事件锚点保持

- [ ] 变体改写前已明确原始故事的最小事件链（谁在何时何地做了什么）。
- [ ] 任一讲法变体均保留核心因果，不因形式变化导致主事件失真。
- [ ] 变体结束后能回链到同一故事母题，而非变成另一条新故事线。

### 21.2 视角与叙述距离变体

- [ ] 至少完成 1 次视角替换（第一/第三人称或角色视角切换）并比较效果差异。
- [ ] 叙述距离与信息暴露节奏匹配，避免“全知透底”破坏张力。
- [ ] 视角切换后角色声音与认知边界保持一致，不发生越界叙述。

### 21.3 时序与结构变体

- [ ] 至少完成 1 次时序重排（顺叙/倒叙/插叙）并验证可读性。
- [ ] 时序改写后读者仍能稳定理解关键因果与转折先后。
- [ ] 结构变体服务冲突强化或主题突出，而非仅做形式炫技。

### 21.4 表达介质与风格约束变体

- [ ] 至少完成 1 次表达约束练习（如对白主导、旁白压缩、镜头化描述）。
- [ ] 风格变体不牺牲事件清晰度，读者可识别角色目标与阻力。
- [ ] 变体之间有可比较指标（张力、清晰度、节奏、角色辨识），便于选优。

### 21.5 变体评估与回流门禁

- [ ] 每次变体输出都记录“保留点/问题点/可迁移技巧”。
- [ ] 最终版本明确继承了哪些有效变体策略，而非回到原稿惯性写法。
- [ ] 周复盘至少抽样 1 组“同故事多讲法”案例并记录结论。

### 21.6 写后返工触发（讲法变体维度）

- [ ] 若变体仅更换措辞、未改变叙述机制 -> 判定“伪变体”，需返工。
- [ ] 若形式变化导致核心事件因果断裂 -> 判定“变体失真”，需返工。
- [ ] 若完成多版本但无评估与回流结论 -> 判定“变体失收敛”，需返工。

## 22. 网络文学连载化创作专项模板（王祥 / 《网络文学创作原理》）

> 用途：将网络文学场景下的“连载节奏 + 读者预期 + 商业化反馈”转为可执行门禁，保障章节持续可读与长期推进稳定性。

### 22.1 连载节奏与更新稳定性

- [ ] 本章已明确在连载节奏中的功能定位（推进主线/扩展支线/角色转折）。
- [ ] 本章结尾设置下一更牵引点（未决冲突/风险升级/目标转向）。
- [ ] 更新计划可执行且稳定，避免长期断更导致叙事断档。

### 22.2 读者预期与爽点兑现

- [ ] 本章至少兑现 1 个读者预期点（冲突爆发/反制成功/关键揭示）。
- [ ] 爽点建立在既有因果链上，禁止凭空开挂或无代价逆转。
- [ ] 爽点后保留后续压力，避免“当章清空全部张力”。

### 22.3 主支线与章节颗粒度控制

- [ ] 主线推进在本章有可观察进展，不被支线长期稀释。
- [ ] 支线内容服务主线目标或人物弧线，不形成无回收岔路。
- [ ] 章节信息密度与篇幅匹配，单章可独立成立且可无缝接续。

### 22.4 平台反馈与迭代修订

- [ ] 本章修订参考有效反馈信号（留存、追更意愿、关键评论聚焦点）。
- [ ] 反馈吸收不破坏核心设定与长期提纲，避免短期迎合导致偏航。
- [ ] 对高频问题有明确修订动作（节奏拖沓/冲突不足/角色失真等）。

### 22.5 长线运营与质量底线

- [ ] 连载策略与叙事质量并行，禁止以纯字数扩张替代结构推进。
- [ ] 关键角色与世界规则在长线更新中保持一致，不因追更压力失稳。
- [ ] 周度复盘包含“更新稳定性 + 质量达标率 + 反馈修订结果”三项记录。

### 22.6 写后返工触发（连载网络文学维度）

- [ ] 若连续多章仅靠悬念拖延、主线无实质推进 -> 判定“连载注水”，需返工。
- [ ] 若为迎合即时反馈频繁改设定并破坏因果 -> 判定“反馈失控”，需返工。
- [ ] 若更新稳定但章节质量持续下滑 -> 判定“运营挤压质量”，需返工。

## 23. 难忘人物塑造专项模板（Linda Seger / 《创造难忘的人物》）

> 用途：将“人物好看但记不住”问题转为可执行检查，确保角色具备辨识度、动机力度、关系张力与可追踪成长。

### 23.1 人物辨识度与记忆点

- [ ] 关键人物具备可复述的核心标签（欲望/弱点/矛盾特征），避免同质化。
- [ ] 角色外显行为与语言风格可区分，不依赖作者说明才能识别。
- [ ] 每个核心人物至少有 1 个可持续使用的记忆点（习惯、价值冲突、行动方式）。

### 23.2 动机、需求与行为一致性

- [ ] 角色“想要什么”与“真正需要什么”在本章有可观察张力。
- [ ] 关键选择由既有动机驱动，非为推进情节而硬性转向。
- [ ] 若角色行为反常，文本提供了足够触发条件与心理依据。

### 23.3 角色关系与冲突网络

- [ ] 角色关系不仅有身份描述，还体现利益/价值/情感冲突。
- [ ] 本章至少有 1 次关系状态变化（靠近/对立/重组）。
- [ ] 配角行动对主角路径产生实质影响，避免工具人化。

### 23.4 背景负载与弧线推进

- [ ] 角色背景信息以“当前行动相关”为原则，避免一次性信息倾倒。
- [ ] 本章推进了角色弧线（认知变化/代价暴露/策略调整）至少一项。
- [ ] 角色缺陷在冲突中产生后果，而不是设定层装饰。

### 23.5 角色语言与场景表现门禁

- [ ] 关键角色的对白、动作、决策在跨场景中保持连续性。
- [ ] 高压场景下角色反应符合其能力边界与价值取向。
- [ ] 角色塑造服务主线冲突推进，而非独立炫技段落。

### 23.6 写后返工触发（人物塑造维度）

- [ ] 若角色可互换而不影响剧情理解 -> 判定“人物失辨识”，需返工。
- [ ] 若角色设定完整但关键场景无行为兑现 -> 判定“人物失行动”，需返工。
- [ ] 若角色关系长期无变化且不影响主线 -> 判定“人物网络失活”，需返工。

## 24. 悬疑小说构建专项模板（Frey / 《悬疑小说创作指导》）

> 用途：将悬疑小说的“谜题设计 + 线索分发 + 误导控制 + 真相揭示”转为可执行门禁，避免只制造神秘感却无法公平解谜或稳定收束。

### 24.1 谜题核心与案件锚点

- [ ] 本章的核心谜题可被一句话定义（谁做了什么、为何可疑、当前未知点是什么）。
- [ ] 案件锚点清晰可见（时间、地点、关键行为至少两项明确）。
- [ ] 本章新增疑点与主谜题存在直接关联，非装饰性悬念。

### 24.2 线索分发与公平解谜

- [ ] 本章至少投放 1 条可回溯线索（读者可在后文验证其作用）。
- [ ] 线索呈现遵循“可见但不直给”原则，避免作者隐瞒关键事实。
- [ ] 关键推理结论可由既有线索链支持，而非终章临时补充信息。

### 24.3 误导与信息差控制

- [ ] 本章至少存在 1 处有效误导（红鲱鱼/错误归因/视角偏差）并可在后文澄清。
- [ ] 误导不与既有事实矛盾，不能靠篡改设定制造反转。
- [ ] 信息差服务张力提升，不导致读者“无从推理”的失公平体验。

### 24.4 嫌疑人与动机强度

- [ ] 关键嫌疑对象具备可验证动机、机会或能力，不是空壳嫌疑人。
- [ ] 主角调查推进会改变嫌疑排序或风险判断，避免原地踏步。
- [ ] 本章至少暴露 1 个人物层面的代价或秘密，推动案件与人物双线前进。

### 24.5 节奏推进与揭示收束

- [ ] 本章在中后段出现一次调查升级（新证据、证词冲突、风险抬升之一）。
- [ ] 结尾保留“未决真相 + 下一步调查入口”，避免悬疑断流。
- [ ] 关键揭示遵循因果递进（铺垫 -> 发现 -> 后果），禁止凭空揭秘。

### 24.6 写后返工触发（悬疑维度）

- [ ] 若关键推理依赖未出现线索或作者临时加设定 -> 判定“解谜失公平”，需返工。
- [ ] 若误导可删除且主线体验无变化 -> 判定“误导失效”，需返工。
- [ ] 若章节制造大量疑点但无任何可验证推进 -> 判定“悬疑空转”，需返工。

## 25. 反套路失误预防专项模板（Mittelmark/Newman / 《如何写砸一本小说》）

> 用途：将“新手高频写作翻车点”转为可执行门禁，优先规避空洞设定、陈词滥调、推进失焦与结构塌陷，确保章节可读性与完成度。

### 25.1 设定与前提失真预防

- [ ] 本章关键设定服务当前冲突，不以“炫设定”替代叙事推进。
- [ ] 世界观规则在本章内自洽，未出现临时改规或自我矛盾。
- [ ] 设定信息投放与角色行动绑定，避免大段说明性灌输。

### 25.2 人物与动机失焦预防

- [ ] 主角本章目标与动机可复述，且与其既有处境一致。
- [ ] 关键行为由角色选择触发，而非作者强推情节。
- [ ] 配角具备独立诉求或阻力功能，避免纯工具人出场。

### 25.3 情节推进与结构塌陷预防

- [ ] 本章至少形成一次“行动 -> 受阻 -> 结果变化”完整链路。
- [ ] 中段不存在长段无冲突信息堆叠，推进强度保持可感知变化。
- [ ] 章节结尾产生下一步行动压力，避免“写完了但没推进”。

### 25.4 语言与表达失效预防

- [ ] 叙述语言以清晰为先，避免辞藻堆砌掩盖信息贫弱。
- [ ] 对白承担行动或关系功能，避免全段可被旁白替代。
- [ ] 陈词滥调与模板化句式已做替换或压缩，保证文本辨识度。

### 25.5 修订策略与完稿纪律

- [ ] 本轮修订明确单一主目标（结构/人物/语言），避免全维度混改失焦。
- [ ] 修订记录能指出至少 1 处“已删除的无效内容”。
- [ ] 章节达到“可评审完稿”标准后再进入细节抛光，避免无限拖稿。

### 25.6 写后返工触发（反套路维度）

- [ ] 若本章主要篇幅用于解释设定、冲突推进极弱 -> 判定“设定挤压叙事”，需返工。
- [ ] 若角色关键行为无法回链到动机与处境 -> 判定“人物驱动失效”，需返工。
- [ ] 若删去多个段落后主线几乎不受影响 -> 判定“结构空耗”，需返工。

## 26. 故事写作实操推进专项模板（蔡骏 / 《故事写作：小说写作实用指南》）

> 用途：将“题材素材积累 + 故事要素建模 + 章节落地推进 + 职业化写作节奏”转为可执行门禁，确保从灵感到成稿的链路稳定可复用。

### 26.1 素材积累与题材定位

- [ ] 本章核心素材来源明确（观察/阅读/历史/社会经验至少一类）。
- [ ] 题材选择与当前故事目标一致，避免题材堆叠导致主线失焦。
- [ ] 素材已转化为可叙事单元（人物冲突/关键事件/场景张力），而非资料摘抄。

### 26.2 故事要素完整性（人物-冲突-场景）

- [ ] 人物目标、阻力与行动路径在本章内可追踪。
- [ ] 冲突具备可升级机制（关系/规则/时间/风险至少一项变化）。
- [ ] 场景承担明确叙事功能（推进主线/揭示人物/制造转折之一）。

### 26.3 章节推进与节奏控制

- [ ] 开场在有限篇幅内完成问题建立，避免长篇铺垫后才进入正题。
- [ ] 中段至少出现一次推进节点（新信息、冲突升级或策略改变）。
- [ ] 结尾形成下一章牵引（未决问题、代价兑现或目标转向）。

### 26.4 叙述视角与信息组织

- [ ] 本章视角稳定且符合叙述边界，避免无理由视角漂移。
- [ ] 信息投放遵循“理解所需最小量”原则，避免解释压过叙事。
- [ ] 关键信息与行动结果绑定，读者可据此理解因果而非靠后置说明。

### 26.5 实用写作流程与修订闭环

- [ ] 本章完成“起稿 -> 通读 -> 定向修订”最小闭环，避免只起草不收束。
- [ ] 修订动作能定位到具体段落问题（结构/人物/语言），而非泛化“润色”。
- [ ] 本章产出满足可继续连载或扩写条件（主线未断、状态已更新、下一步可执行）。

### 26.6 写后返工触发（实操流程维度）

- [ ] 若素材很多但无法形成有效故事推进 -> 判定“素材失转化”，需返工。
- [ ] 若章节信息完整却缺少冲突与行动变化 -> 判定“叙事失驱动”，需返工。
- [ ] 若多轮修订后仍无法稳定进入下一章 -> 判定“流程失闭环”，需返工。

## 27. 灵感捕捉与创意转化专项模板（Fred White / 《作家的灵感宝库》）

> 用途：将“灵感获取 -> 记录沉淀 -> 创意扩展 -> 故事化落地”转为可执行门禁，降低创意流失与起稿卡壳，提升灵感到章节的转化效率。

### 27.1 灵感捕捉与记录机制

- [ ] 本章核心创意来源可追溯（观察/提问/联想/阅读触发至少一类）。
- [ ] 灵感已沉淀为可复用记录（关键词、场景句、冲突种子之一），非仅短暂想法。
- [ ] 本章至少使用 1 条历史灵感记录，避免“有库不用”。

### 27.2 创意扩展与变体推演

- [ ] 核心创意至少做 1 次变体扩展（人物替换/场景转置/冲突升级之一）。
- [ ] 扩展结果保持主命题一致，不因脑洞发散导致主线偏航。
- [ ] 变体筛选有取舍依据（可写性、冲突强度、后续可持续性）。

### 27.3 从点子到故事链路

- [ ] 本章将创意转化为“人物目标 -> 行动 -> 阻力 -> 结果”最小故事链。
- [ ] 创意落地后能带来可观察状态变化，不停留在概念展示。
- [ ] 章节结尾保留下一步创意推进入口（新问题/新代价/新目标）。

### 27.4 角色与冲突驱动融合

- [ ] 灵感点与角色动机绑定，避免“好点子+弱人物”的割裂。
- [ ] 冲突由创意触发并反向塑造角色选择，而非孤立情节点缀。
- [ ] 关键场景中至少有一次由创意引发的关系或风险升级。

### 27.5 创作习惯与流程稳定性

- [ ] 本章执行“收集 -> 选题 -> 起稿 -> 复盘”最小流程，避免灵感堆积不产出。
- [ ] 对卡壳段落执行定向重启动作（换视角/换问题/换冲突）并记录结果。
- [ ] 周复盘能指出灵感库新增量、命中率与废弃原因，支持持续优化。

### 27.6 写后返工触发（灵感转化维度）

- [ ] 若灵感数量很多但章节推进无实质变化 -> 判定“创意失转化”，需返工。
- [ ] 若创意表达依赖解释、缺少行动与冲突承载 -> 判定“点子悬浮”，需返工。
- [ ] 若连续多章重复同类创意模板且无升级 -> 判定“创意固化”，需返工。

## 28. 读者牵引与折磨式推进专项模板（许荣哲 / 《小说课Ⅰ：折磨读者的秘密》）

> 用途：将“读者期待管理 + 选择压力 + 延迟满足 + 反转兑现”转为可执行门禁，确保章节具备持续牵引力而非平铺直叙。

### 28.1 读者问题建立与期待绑定

- [ ] 开场阶段明确抛出核心问题，读者可快速识别“想知道什么”。
- [ ] 本章关键期待与主角目标绑定，避免悬念与主线分离。
- [ ] 本章至少建立 1 个“短期可追问”的子问题，支撑中段阅读动力。

### 28.2 选择压力与代价设计

- [ ] 关键节点存在真实选择压力（至少两条路径且均有代价）。
- [ ] 主角选择后立即引发局面变化，避免“选择无后果”。
- [ ] 代价呈现具体可见（关系、风险、时间、资源至少一项）。

### 28.3 延迟满足与信息节拍

- [ ] 重要答案不提前一次性给出，采用分段揭示维持张力。
- [ ] 每次揭示同时引出新不确定性，形成“解答一层、再开一层”。
- [ ] 信息延迟不依赖硬性隐瞒，读者仍可凭已知信息推理。

### 28.4 反转铺垫与公平兑现

- [ ] 反转前有可回溯铺垫，避免“凭空翻盘”。
- [ ] 反转改变人物关系或主线风险，不是仅做情绪刺激。
- [ ] 反转后能回链此前线索，保持因果与逻辑一致。

### 28.5 章节钩子与连读驱动

- [ ] 章末保留未决冲突或新风险，驱动读者进入下一章。
- [ ] 章末钩子与本章冲突链连续，避免强插悬念。
- [ ] 连续章节的钩子强度有层级变化，避免同质化疲劳。

### 28.6 写后返工触发（读者牵引维度）

- [ ] 若本章信息完整但读者问题不明确 -> 判定“期待失焦”，需返工。
- [ ] 若关键选择不改变局势或无代价 -> 判定“选择失效”，需返工。
- [ ] 若反转无法回链铺垫或章末钩子可删 -> 判定“牵引失真”，需返工。
