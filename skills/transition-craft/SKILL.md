# 🔄 转场技巧 (Transition Craft)

## 概述

转场是连接场景的桥梁。好的转场让读者自然过渡，差的转场让读者迷失或出戏。

## 技能定位与边界

| 相关技能 | 边界划分 |
|----------|----------|
| **timeline-craft** | 管时间跳跃的设计，本技能管过渡的执行 |
| **tension-chapter** | 管章节内场景编排，本技能管场景间的连接 |
| **multiline-narrative** | 管多线结构，本技能管线索间的切换过渡 |

---

## 一、转场类型

### 按功能分类

| 类型 | 作用 | 示例 |
|------|------|------|
| **时间转场** | 跳过时间 | "三天后"、季节变化 |
| **空间转场** | 切换地点 | 从城市到乡村 |
| **视角转场** | 切换POV | 从主角到配角 |
| **情绪转场** | 切换氛围 | 从紧张到舒缓 |
| **线索转场** | 切换情节线 | 从A线到B线 |

### 按技法分类

| 技法 | 说明 | 示例 |
|------|------|------|
| **硬切** | 直接切换，无过渡 | 章节分隔、空行 |
| **软切** | 有过渡元素 | 用意象或声音连接 |
| **溶解** | 渐变过渡 | 一个场景淡出，另一个淡入 |
| **匹配** | 用相似元素连接 | 这边的月亮 → 那边的月亮 |
| **对比** | 用反差连接 | 婚礼的欢笑 → 葬礼的哭泣 |

## 二、转场技巧

### 1. 硬切转场

**特点**：直接切换，不加过渡

**适用**：
- 章节切换
- 时间跳跃明显
- 需要制造冲击感

**执行**：
```
场景A结束。

***

场景B开始。
```

### 2. 匹配转场

**特点**：用相似元素连接两个场景

**类型**：
| 类型 | 示例 |
|------|------|
| **视觉匹配** | 圆月 → 圆盘 |
| **声音匹配** | 枪声 → 汽车回火声 |
| **动作匹配** | 她挥手告别 → 他挥手打车 |
| **台词匹配** | "明天见" → 第二天早上 |
| **情绪匹配** | 两个场景都是孤独感 |

**示例**：
> 她看着窗外的满月，泪水模糊了视线。
>
> 三千公里外，同一轮月亮照在他的窗台上。他不知道她在哭。

### 3. 对比转场

**特点**：用反差连接，制造冲击

**示例**：
> 教堂里，婚礼进行曲响起，新人交换戒指。
>
> 医院里，心电图变成一条直线。

### 4. 钩子转场

**特点**：在悬念处切换，制造期待

**示例**：
> 门开了，站在门口的是——
>
> [切换到另一场景]
>
> 与此同时，城市另一端...

### 5. 蒙太奇转场

**特点**：一系列快速场景压缩时间

**适用**：
- 展示时间流逝
- 展示重复性活动
- 展示并行事件

**示例**：
> 一月，他开始练习。
> 三月，他摔了一百次。
> 六月，他第一次站稳了三秒。
> 九月，他站在了领奖台上。

## 三、转场信号

### 时间信号

| 类型 | 示例 |
|------|------|
| **明确标记** | "三天后"、"第二年春天" |
| **环境变化** | 雪融化了、树叶变黄 |
| **状态变化** | 伤口愈合了、头发长了 |
| **对话暗示** | "自从那件事..." |

### 空间信号

| 类型 | 示例 |
|------|------|
| **地点标记** | "北京，国贸大厦" |
| **环境描写** | 描述新地点的特征 |
| **角色移动** | "他下了飞机，热带的风扑面而来" |

### 视角信号

| 类型 | 示例 |
|------|------|
| **人名开头** | "李明站在窗前..." |
| **章节标题** | "第三章 · 苏婉的秘密" |
| **叙事风格变化** | 不同角色有不同的内心独白风格 |

## 四、转场节奏

### 节奏控制

| 节奏 | 转场方式 | 效果 |
|------|----------|------|
| **快节奏** | 硬切、短场景、蒙太奇 | 紧张、紧凑 |
| **慢节奏** | 软切、详细过渡 | 舒缓、沉浸 |
| **变奏** | 快慢交替 | 有呼吸感 |

### 转场频率

| 场景长度 | 转场感受 |
|----------|----------|
| 很短（几段） | 快节奏、电影感 |
| 中等（1-3页） | 标准节奏 |
| 很长（5页+） | 慢节奏、沉浸式 |

---

## 五、常见问题

| 问题 | 表现 | 修复 |
|------|------|------|
| **跳跃迷失** | 读者不知道现在在哪 | 添加空间/时间锚点 |
| **过渡生硬** | 切换太突然 | 使用匹配或软切 |
| **过渡冗长** | 花太多篇幅过渡 | 简化或使用硬切 |
| **节奏单一** | 每次都用同样的转场 | 变换转场技法 |

## 六、检查清单

### 基础检查
- [ ] 读者是否知道现在在哪里？
- [ ] 读者是否知道现在是什么时候？
- [ ] 读者是否知道现在跟着谁？

### 技法检查
- [ ] 转场方式是否适合当前节奏？
- [ ] 是否有过渡信号？
- [ ] 转场是否自然流畅？

### 节奏检查
- [ ] 转场频率是否合适？
- [ ] 是否有快慢变化？
- [ ] 是否有不必要的过渡可以删除？

## 与其他技能的协作

- **← timeline-craft**：时间跳跃需要转场执行
- **← multiline-narrative**：多线切换需要转场技巧
- **← tension-chapter**：场景编排决定转场位置
- **→ pov-system**：视角切换是转场的一种
