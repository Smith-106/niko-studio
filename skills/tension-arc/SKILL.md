# 全书张力架构 (Tension Arc)

## 概述

本技能负责规划整部作品的张力架构，确定关键节点位置，形成宏观节奏蓝图。是三个张力技能中最高层级的规划工具。

## 使用时机

- 新书开始前规划整体节奏
- 大纲完成后验证张力分布
- 作品"后半部分乏力"时进行诊断
- 改稿时重新调整整体结构

## 经典张力架构模型

### 三幕式（推荐入门）

```
张力
 ↑
 │                              ★ 高潮
 │                           ╱    ╲
 │              ◆ 中点    ╱        ╲
 │           ╱         ╱            ╲
 │    ● 激励╱       ╱                ╲ ◇ 结局
 │      ╱        ╱
 │   ╱       ╱
 │╱______╱_________________________________→ 进度
 0%    12%    25%    50%    75%    90%   100%

● 激励事件(10-15%) - 打破平衡，启动故事
◆ 中点转折(45-55%) - 假胜利/假失败，提升赌注
★ 高潮(75-90%) - 最大对抗，决定性时刻
◇ 结局(90-100%) - 新平衡，情感落点
```

适用：通用故事、电影化叙事、商业小说

### 英雄之旅

```
12阶段循环：

普通世界 → 冒险召唤 → 拒绝召唤 → 遇见导师
    ↓                                    ↓
  回归  ←  复活  ←  回程  ←  报酬  ←  磨难
    ↓         ↑
  新生活    考验、盟友、敌人 → 接近洞穴 → 进入深渊

关键张力节点：
- 跨越门槛(25%) - 进入新世界
- 进入深渊(50%) - 最大考验
- 复活(75-85%) - 生死时刻
```

适用：奇幻、冒险、成长故事

 0%     25%      50%       75%    90%  100%

适用：悬疑、惊悚、反转故事

### 多线交织

```
      A线 ─────●─────────●────────────●────┐
                                           │
      B线 ───────●───────────●─────────────┼──★ 汇聚高潮
                                           │
      C线 ─────────●─────────────●─────────┘

各线独立发展，在关键节点产生交叉影响，
最终汇聚到一个总高潮。
```

适用：群像、史诗、权谋故事

## 关键节点定义

| 节点 | 位置 | 功能 | 诊断标准 |
|------|------|------|----------|
| **激励事件** | 10-15% | 打破平衡，启动故事 | 是否有明确的"不能回头"时刻？ |
| **第一转折** | 20-25% | 进入第二幕，建立目标 | 主角是否有了明确追求？ |
| **中点** | 45-55% | 假胜/假败，提升赌注 | 是否改变了故事走向？ |
| **第二转折** | 70-80% | 最低谷，逼向高潮 | 主角是否面临最大危机？ |
| **高潮** | 80-90% | 终极对决，不可逆决定 | 是否解决了核心冲突？ |
| **结局** | 90-100% | 新平衡，情感收束 | 是否有满足感？ |

## 流程

### 第一步：选择架构模型

根据故事类型选择基础模型：

| 故事类型 | 推荐模型 |
|----------|----------|
| 爱情、职场、生活 | 三幕式 |
| 奇幻、冒险、武侠 | 英雄之旅 |
| 悬疑、推理、惊悚 | 双高潮 |
| 史诗、权谋、群像 | 多线交织 |

### 第二步：定位关键节点

```
请提供故事大纲或章节列表，我将：
1. 识别现有关键节点位置
2. 与理想模型对比
3. 标注偏差和缺失
```

### 第三步：诊断问题

| 问题类型 | 表现 | 影响 |
|----------|------|------|
| **激励过晚** | 超过20%才启动故事 | 开头拖沓，读者流失 |
| **中点缺失** | 50%处无明显转折 | 中段乏力，节奏平淡 |
| **高潮过早** | 70%前就达到顶峰 | 后续拖尾，虎头蛇尾 |
| **高潮不足** | 最高点张力不够 | 结局缺乏冲击力 |
| **结局拖沓** | 高潮后超过15%篇幅 | 读者失去耐心 |
| **节点堆积** | 多个大事件扎堆 | 读者无法消化 |

### 第四步：调整建议

提供具体的结构调整方案：
- 节点位置微调
- 章节合并或拆分
- 增删情节点
- 调整副线节奏

## 张力强度规划

全书各阶段的张力范围建议：

| 阶段 | 位置 | 张力范围 | 说明 |
|------|------|----------|------|
| 开篇 | 0-10% | 3-5 | 建立常态，但要有吸引力 |
| 第一幕 | 10-25% | 4-7 | 逐步升级，建立冲突 |
| 第二幕前半 | 25-50% | 5-8 | 发展对抗，递进升级 |
| 中点 | 50% | 7-8 | 重大转折，提升赌注 |
| 第二幕后半 | 50-75% | 6-9 | 加速推进，逼向危机 |
| 高潮 | 75-90% | 9-10 | 最大张力，决战时刻 |
| 结局 | 90-100% | 4-6 | 情绪释放，新平衡 |

## 与其他技能的协作

- **→ tension-chapter**：确定节点后，细化每章的张力编排
- **→ tension-scene**：为关键节点设计高张力场景
- **← 22-steps-outline**：大纲结构决定节点布局
- **← pyramid-structure**：金字塔结构与张力架构互补
