# 🎭 四个自我技能包 (Four Selves)

> **核心理念**：每个角色都有四个自我——社会自我、个人自我、私密自我和隐藏自我。这四层结构是塑造立体人物的关键。

## 技能定位与边界

| 相关技能 | 边界划分 |
|----------|----------|
| **character-forge** | 基础塑造框架，本技能深化其心理结构 |
| **true-character** | 通过两难选择揭示隐藏自我，与本技能配合使用 |
| **psychology-craft** | 心理描写技法，可用于展示四个自我的具体表现 |
| **dialogue-system** | 不同自我层次的对话会有不同的潜台词 |

**人物系统三层结构**：
```
character-forge (塑造层) → four-selves (深化层) → true-character (验证层)
     基础框架              四层心理结构           两难选择验证
```

**本技能职责**：人物的**心理层次结构**——四层自我模型及其冲突设计
**不负责**：基础塑造（character-forge）、描写技法（psychology-craft）

## 🔧 四个自我模型

### 第一层：社会自我 (Social Self)

> 角色在公众场合展示的面具。

#### 特征
- 职业形象、社会地位
- 刻意维护的公众形象
- 符合社会期待的行为模式

#### 示例
```
警察局长王德明：
社会自我 = 铁面无私、雷厉风行的执法者
在媒体面前总是西装笔挺，语气坚定
```

---

### 第二层：个人自我 (Personal Self)

> 角色在亲密关系中展示的一面。

#### 特征
- 家人、朋友眼中的形象
- 比社会自我更真实
- 仍有所保留

#### 示例
```
王德明在家中：
个人自我 = 疲惫的丈夫，沉默的父亲
回家后会摘下领带，瘫在沙发上一言不发
偶尔会给女儿买她喜欢的草莓蛋糕
```

---

### 第三层：私密自我 (Private Self)

> 角色独处时的真实状态。

#### 特征
- 只有自己知道的习惯
- 内心独白
- 真实的恐惧和欲望

#### 示例
```
王德明独处时：
私密自我 = 焦虑的失眠者
深夜在书房里反复翻看一个未结案件的照片
对着镜子练习第二天的发言，手会微微发抖
```

---

### 第四层：隐藏自我 (Hidden Self)

> 连角色自己都不愿承认的真相。

#### 特征
- 潜意识层面
- 压抑的欲望或创伤
- 故事高潮时才会揭示

#### 示例
```
王德明的隐藏自我：
隐藏自我 = 二十年前的目击者
他亲眼看到那个人被杀害
却因为恐惧选择沉默
整个职业生涯都是对那份沉默的救赎
```

## 🎬 四个自我的叙事应用

### 递进揭示策略

| 故事阶段 | 揭示层次 | 作用 |
|---------|---------|------|
| 开篇 | 社会自我 | 建立第一印象 |
| 发展 | 个人自我 | 增加亲近感 |
| 中段 | 私密自我 | 激发共情 |
| 高潮 | 隐藏自我 | 震撼读者 |

### 冲突设计：层次间的撕裂

> 最强大的戏剧冲突来自角色被迫在不同自我之间选择。

```
困境设计示例：
王德明必须逮捕自己的恩师（社会自我 vs 个人自我）
→ 或者必须在法庭上作证（私密自我暴露）
→ 最终那个二十年前的秘密被揭开（隐藏自我曝光）
```
