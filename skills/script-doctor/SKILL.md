# 🩺 剧本医生技能包 (Script Doctor)

> **核心理念**：像医生诊断病人一样诊断故事。识别陈词滥调，评估张力曲线，开出精准的修改处方。

## 📋 技能元数据

```yaml
skill_id: script-doctor
version: 1.0.0
category: evaluation
theory_source: "好莱坞剧本医生实践 + 编剧理论"
triggers:
  - "剧本诊断"
  - "故事问题"
  - "陈词滥调"
  - "张力评估"
  - "修改建议"
```

## 🔧 诊断框架

### 五大诊断维度

| 维度 | 权重 | 检查内容 |
|------|------|---------|
| **张力曲线** | 25% | 冲突是否持续升级？ |
| **陈词滥调** | 20% | 是否有老套桥段？ |
| **角色一致性** | 20% | 行为是否符合人设？ |
| **节奏控制** | 20% | 快慢是否得当？ |
| **逻辑漏洞** | 15% | 因果是否成立？ |

### 理想张力曲线

```

  ↑

  │          ╱╲
  │         ╱  ╲
  │   ╱╲   ╱    ╲
  │  ╱  ╲ ╱      ╲
  │ ╱    ╱        ╲___
  │╱                  
  └────────────────────→ 时间
   开篇  发展  高潮  结局
```

### 问题模式识别

```
问题1：平坦曲线
  │____________________
  └──────────────────→
  诊断：缺乏冲突升级
  处方：每场戏增加新障碍

问题2：过早高潮
  │   ★
  │  ╱ ╲___________
  │ ╱
  └──────────────────→
  诊断：后半段乏力
  处方：分割高潮，设置假高潮

问题3：波动过大
  │ ★  ★  ★  ★
  │╱ ╲╱ ╲╱ ╲╱ ╲
  └──────────────────→
  诊断：情感疲劳
  处方：建立主冲突线，控制副线

问题4：缺乏喘息
  │        ╱
  │      ╱
  │    ╱
  │  ╱
  └──────────────────→
  诊断：读者喘不过气
  处方：插入过渡场景
```

## 🔧 诊断流程

### Step 1: 快速扫描

```markdown
□ 开篇是否陈词滥调？
□ 主角是否有明确目标？
□ 对手是否有实质威胁？
□ 是否有明显的逻辑漏洞？
□ 结局是否令人满意？
```
