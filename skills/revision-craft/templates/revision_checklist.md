# 修订检查清单

## 结构层
- [ ] 主线目标是否清晰且持续推进。
- [ ] 关键转折是否有因果支撑。
- [ ] 是否删除了重复功能段落。

## 节奏层
- [ ] 关键冲突段获得足够篇幅。
- [ ] 解释段未压过行动段。
- [ ] 高压与缓冲节奏交替合理。

## 表达层
- [ ] 对话具备意图与潜台词。
- [ ] 描写密度与场景目标匹配。
- [ ] 抽象词被具体细节替换。

## 一致性层
- [ ] 人称、时态、术语保持一致。
- [ ] 角色口吻与行为前后一致。
- [ ] 世界规则未被无理由破坏。

## 输出层
- [ ] 记录本轮修改点与原因。
- [ ] 标注仍待处理的问题清单。
- [ ] 给出下一轮修订优先级。
