# Revision Craft

## 适用场景

- 初稿可读但质量不稳定。
- 需要在不改核心意图的前提下提升表达。
- 需要一轮可追踪的修订流程。

## 执行步骤

1. 做问题标注。
   - 标出结构问题（顺序、重复、跳跃）。
   - 标出表达问题（冗长、模糊、口吻漂移）。
2. 按优先级修订。
   - 先修结构，再修段落，再修句子。
   - 每次只处理一类问题，避免相互污染。
3. 执行最小修改。
   - 保留原意与关键信息。
   - 删除冗余，不做无关扩写。
4. 一致性回查。
   - 术语一致。
   - 时态与人称一致。
   - 语气与目标读者匹配。
5. 输出修订说明。
   - 列出改动点。
   - 说明改动原因与收益。

## 输出模板

```markdown
## 修订结果
[修订后文本]

## 修改说明
1. [位置]：[问题] -> [修改]
2. [位置]：[问题] -> [修改]
```
