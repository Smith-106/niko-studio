# 章节张力曲线 (Tension Chapter)

## 适用边界

- 适用：章节内多个场景的节奏编排与章尾钩子优化。
- 不适用：单场景局部张力打磨（应转 `tension-scene`）。
- 不适用：全书节点布局与高潮位置（应转 `tension-arc`）。

## 概述

章节由多个场景组成，本技能负责编排场景之间的张力节奏，避免节奏单调或读者疲劳，确保每章都有吸引力。

## 使用时机

- 规划章节大纲时设计场景编排
- 章节初稿完成后检查整体节奏
- 读者反馈"某章很无聊"时进行诊断

## 章节张力四原则

| 原则 | 说明 | 违反后果 |
|------|------|----------|
| **对比法则** | 高张力场景后需要喘息空间 | 读者疲劳、情绪麻木 |
| **递进法则** | 章节内多个高潮应逐步升级 | 后续高潮失去冲击力 |
| **钩子法则** | 章节结尾必须留有悬念 | 读者放下书不再继续 |
| **节点法则** | 每章至少一个"不可逆"情节点 | 章节可有可无、无意义 |

## 章节结构模板

### 经典三段式

```
┌─────────────────────────────────────────┐
│  开场(15%)   中段发展(70%)   结尾钩子(15%) │
│     ↗            ∿  ↗           ↑↑      │
│  快速切入     起伏递进      悬念峰值      │
└─────────────────────────────────────────┘

开场：快速建立本章核心冲突
中段：通过多个场景递进发展
结尾：峰值或悬念，驱动下一章
```

### 四场景编排示例

```
场景1 [中] → 场景2 [低] → 场景3 [高] → 场景4 [悬]
  建立冲突    情感缓冲     高潮爆发     钩子结尾

张力曲线：
     ┌──────┐
     │      │ ←场景3高潮
  ┌──┘      └──┐
  │            │ ←场景4悬念
──┘            └─────
场景1  场景2  场景3  场景4
```

### 常用编排模式

| 模式 | 张力序列 | 适用情况 |
|------|----------|----------|
| **标准递进** | 中→低→高→悬 | 通用，大多数章节 |
| **双峰模式** | 高→低→高→悬 | 需要两个重要事件 |
| **缓起急收** | 低→中→中→高 | 铺垫章节、转折前 |
| **急起缓落** | 高→中→低→中 | 高潮后的过渡章节 |

## 流程

### 第一步：绘制章节张力图

```
请提供章节大纲或场景列表，我将：
1. 为每个场景标注张力等级
2. 绘制章节张力曲线
3. 标注关键节点位置
```

### 第二步：诊断问题

| 警告类型 | 触发条件 | 说明 |
|----------|----------|------|
| **平坦警告** | 连续2+场景张力相近 | 节奏单调，缺乏起伏 |
| **疲劳警告** | 连续2+高张力场景无缓冲 | 读者情绪过载 |
| **泄气警告** | 章节结尾张力低于开场 | 失去阅读驱动力 |
| **断裂警告** | 相邻场景张力跳跃过大 | 缺乏过渡，不自然 |
| **空转警告** | 无"不可逆"情节节点 | 章节缺乏实质进展 |

### 第三步：优化建议

**平坦问题**：
- 插入突发事件打破节奏
- 添加人物冲突或内心挣扎
- 揭示信息制造紧张感

**疲劳问题**：
- 在高潮间插入缓冲场景
- 用反思、对话场景调节
- 缩短高张力场景篇幅

**泄气问题**：
- 重新设计章节结尾
- 添加悬念钩子或新问题
- 将解决场景移到下一章

**断裂问题**：
- 添加过渡段落或场景
- 用人物反应铺垫情绪
- 调整场景顺序

## 与其他技能的协作

- **← tension-scene**：先用场景技能打磨单个场景
- **→ tension-arc**：检查章节是否符合全书节奏规划
- **← 22-steps-outline**：大纲结构影响章节功能定位
