# ⚔️ 冲突升级 (Conflict Escalation)

## 概述

冲突是故事的引擎。好的冲突不是一成不变的，而是不断升级——赌注越来越高，障碍越来越难，直到高潮爆发。

## 技能定位与边界

| 相关技能 | 边界划分 |
|----------|----------|
| **tension-arc** | 张力曲线是结果，冲突升级是实现手段 |
| **suspense-craft** | 威胁情境是冲突类型之一，本技能更系统 |
| **character-forge** | 角色欲望驱动冲突，本技能管冲突设计 |

**本技能职责**：冲突的**设计与升级策略**
**不负责**：张力曲线形态（tension-arc）、悬念技巧（suspense-craft）

## 一、冲突层次模型

### 四层冲突体系

```
┌─────────────────────────────────────┐
│ 第四层：内在冲突 (Internal)          │
│ 角色与自我的斗争                     │
├─────────────────────────────────────┤
│ 第三层：人际冲突 (Interpersonal)     │
│ 角色与他人的对抗                     │
├─────────────────────────────────────┤
│ 第二层：社会冲突 (Social)            │
│ 角色与群体/制度的对抗                │
├─────────────────────────────────────┤
│ 第一层：外部冲突 (External)          │
│ 角色与环境/命运的对抗                │
└─────────────────────────────────────┘
```

### 层次详解

| 层次 | 定义 | 示例 |
|------|------|------|
| **外部冲突** | 自然灾害、物理障碍、生存威胁 | 暴风雨、追杀、疾病 |
| **社会冲突** | 法律、制度、阶级、文化 | 不公正审判、阶级歧视 |
| **人际冲突** | 对手、敌人、关系破裂 | 反派对抗、家庭矛盾 |
| **内在冲突** | 恐惧、欲望、道德困境 | 想救人又怕死、爱与责任 |

### 层次组合

**最有力的故事同时包含多个层次**：

```
示例：《肖申克的救赎》

外部冲突：监狱的物理限制
社会冲突：腐败的司法制度
人际冲突：典狱长的压迫
内在冲突：保持希望 vs 接受绝望
```

## 二、冲突升级策略

### 升级公式

```
升级 = 赌注提高 + 障碍加强 + 时间压缩
```

### 五种升级方式

| 方式 | 说明 | 示例 |
|------|------|------|
| **提高赌注** | 失败后果更严重 | 从丢工作 → 到丢命 |
| **增加障碍** | 新的阻碍出现 | 解决一个问题，冒出三个 |
| **缩短时间** | 截止日期逼近 | 从一周 → 到三天 → 到今晚 |
| **减少资源** | 可用资源减少 | 盟友背叛、武器丢失 |
| **揭示真相** | 发现情况更糟 | 以为是一个敌人，其实是一个组织 |

### 升级节奏

```
故事进度与冲突强度：

强度
  ↑
  │                    ████ 高潮
  │                ████
  │            ████
  │        ████
  │    ████
  │████
  └────────────────────────→ 进度
   25%    50%    75%   100%

每个阶段都应比前一阶段更激烈
```

## 三、障碍设计

### 障碍类型

| 类型 | 定义 | 示例 |
|------|------|------|
| **物理障碍** | 实际的阻挡 | 锁着的门、悬崖、距离 |
| **人物障碍** | 对手/敌人 | 反派、竞争者、阻挠者 |
| **信息障碍** | 缺乏关键信息 | 不知道密码、不知道真相 |
| **资源障碍** | 缺乏资源 | 没钱、没武器、没时间 |
| **能力障碍** | 能力不足 | 不会游泳却要过河 |
| **心理障碍** | 内心阻碍 | 恐惧、创伤、道德顾虑 |
| **关系障碍** | 关系阻碍 | 需要帮助的人拒绝合作 |

### 障碍递进原则

| 原则 | 说明 |
|------|------|
| **递进性** | 后面的障碍比前面更难 |
| **多样性** | 不同类型的障碍交替出现 |
| **相关性** | 障碍与角色弱点相关 |
| **必要性** | 每个障碍都推动情节或揭示角色 |

### 障碍设计检查

- [ ] 障碍是否逐步升级？
- [ ] 障碍类型是否多样？
- [ ] 障碍是否针对角色弱点？
- [ ] 克服障碍是否需要角色成长？

## 四、赌注设计

### 赌注层次

```
个人赌注（最基础）
├── 生命安全
├── 健康/身体
├── 自由
└── 财产/地位

关系赌注（更深刻）
├── 爱人/家人的安危
├── 友情/信任
├── 归属感
└── 被接纳/被爱

价值赌注（最深刻）
├── 信念/原则
├── 身份认同
├── 人生意义
└── 灵魂/道德
```

### 赌注升级路径

```
典型升级：个人 → 关系 → 价值

第一幕：主角可能丢工作（个人）
第二幕：主角的家人受到威胁（关系）
第三幕：主角必须违背原则才能救家人（价值）
```

### 赌注设计检查

- [ ] 读者是否清楚知道赌注是什么？
- [ ] 赌注是否随故事发展升级？
- [ ] 最终赌注是否足够重大？
- [ ] 赌注是否与角色核心相关？

## 五、对手设计

### 有效对手的特征

| 特征 | 说明 |
|------|------|
| **实力匹配** | 对手至少与主角旗鼓相当 |
| **目标冲突** | 对手的目标直接阻碍主角 |
| **不可妥协** | 双方无法通过谈判解决 |
| **有理由** | 对手有自己的动机和逻辑 |

### 对手升级策略

| 阶段 | 对手表现 |
|------|----------|
| **初期** | 展示实力，给主角下马威 |
| **中期** | 对手反击，挫败主角计划 |
| **后期** | 对手领先，主角陷入绝境 |
| **高潮** | 全力对决，胜负在此一举 |

### 对手层次

```
直接对手（明面）
├── 反派/敌人
└── 竞争者

间接对手（暗面）
├── 背后的操纵者
├── 制度/系统
└── 主角自己的弱点
```

## 六、冲突诊断

### 问题类型

| 问题 | 表现 | 修复 |
|------|------|------|
| **冲突平淡** | 赌注不够高 | 提高失败后果 |
| **冲突重复** | 同类障碍反复出现 | 增加障碍多样性 |
| **升级断层** | 突然变难，缺乏过渡 | 添加中间障碍 |
| **对手太弱** | 主角轻松获胜 | 增强对手实力 |
| **对手太强** | 主角胜利不可信 | 给主角成长机会 |
| **冲突单一** | 只有一个层次 | 添加多层次冲突 |

### 冲突密度检查

每章应包含：
- [ ] 至少一个活跃冲突
- [ ] 冲突强度不低于上一章
- [ ] 障碍与赌注清晰

## 与其他技能的协作

- **→ tension-arc**：冲突升级驱动张力曲线上升
- **← character-forge**：角色欲望和弱点决定冲突设计
- **← suspense-craft**：威胁情境是冲突的具体表现
- **→ ending-craft**：冲突在结尾得到解决
