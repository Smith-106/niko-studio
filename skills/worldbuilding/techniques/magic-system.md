# 魔法系统设计

## 目标
构建可叙事、可约束、可复用的超常系统，让能力既能推动剧情，也能制造代价与冲突。

## 设计框架
1. 来源与门槛
   - 力量来源：血统、契约、技术、仪式或信仰。
   - 获取门槛：学习成本、天赋限制、资源消耗。
2. 运作机制
   - 触发条件：时间、地点、媒介、情绪或关键词。
   - 稳定规则：可重复验证的因果链。
3. 代价与副作用
   - 直接代价：寿命、记忆、身体损耗、社会惩罚。
   - 延迟后果：人格偏移、关系破裂、世界失衡。
4. 约束与例外
   - 明确边界：什么不能做、为什么不能做。
   - 例外条件：极少数破例需满足高成本前提。

## 快速检查
- 能力上限是否明确，避免万能解法。
- 代价是否与收益匹配，且能在剧情中兑现。
- 主角能否通过理解规则而非开挂获胜。
