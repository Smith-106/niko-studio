## 🔧 核心概念

### 镜像人物 (Mirror Character)

> 与主角相似但走向不同道路的角色——"如果主角做了另一个选择会变成什么样"。

#### 特征
- 与主角有相似的起点或处境
- 面对类似选择时做出不同决定
- 展示主角"可能成为"的另一种命运

#### 示例
```
《绝命毒师》
主角：Walter White（化学教师 → 毒枭）
镜像：Gale Boetticher（化学天才 → 选择服从）

两人都是化学天才，都进入毒品世界
Walter选择掌控一切 → 毁灭
Gale选择服从 → 被杀

→ 镜像揭示：无论哪条路都是悲剧
```

---

### 陪衬人物 (Foil Character)

> 与主角形成鲜明对比，通过反差凸显主角特质的角色。

#### 特征
- 性格/价值观与主角截然相反
- 经常与主角产生冲突
- 让主角的特质更加突出

#### 示例
```
《福尔摩斯》
主角：Holmes（理性、孤僻、观察力）
陪衬：Watson（感性、社交、普通人视角）

Watson的"普通"凸显了Holmes的"非凡"
Watson的"感性"凸显了Holmes的"理性"
```

## 🎬 四角对立模型

### 概念

> 四个主要角色构成价值观坐标系，在对角线上形成最大冲突。

```
            道德高尚
               ↑
     理想主义者  │  务实改革派
    (主角?)    │
               │
←────────────────────────→
  方法温和    │    方法激进
               │
     循规蹈矩者  │  极端主义者
               │   (反派?)
               ↓
            道德堕落
```

### 四角色示例

```
《黑暗骑士》四角对立：

         正义
           ↑
  Batman   │  Gordon
  (法外)   │  (法内)
           │
←─────────────────→
  个人正义   │   制度正义
           │
  小丑      │  Harvey Dent
  (混乱)   │  (堕落)
           ↓
         邪恶

每对对角线都是核心冲突：
- Batman vs Joker：秩序 vs 混乱
- Gordon vs Dent：坚守 vs 堕落
```

## 🔧 设计技巧

### 技巧一：镜像设计三步法

```
1. 确定主角的核心选择
   例：选择用暴力解决问题

2. 创造相似起点的角色
   例：同样遭遇不公的人

3. 让镜像做相反选择
   例：选择用法律途径解决
   
4. 展示两条路的结果
   → 形成价值观对话
```

### 技巧二：陪衬设计公式

```
陪衬特质 = 主角特质的反面 + 适度夸张

示例：
主角：沉默寡言
陪衬：话痨 + 夸张（说话像开机关枪）

主角：极度理性
陪衬：极度感性 + 夸张（动不动就哭）
```

### 技巧三：动态关系设计

> 镜像和陪衬关系不是静态的，应该随故事发展变化。

```
阶段1：陪衬（对比）
  → 两人观点不同，经常冲突

阶段2：镜像（相似）
  → 面对危机，发现彼此相似

阶段3：融合或分离
  → 要么理解彼此，要么彻底决裂
```
