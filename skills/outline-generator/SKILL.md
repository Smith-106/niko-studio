# Outline Generator

## 适用场景

- 从 0 到 1 起草文章、小说、方案提纲。
- 已有素材但缺少清晰结构。
- 需要快速产出可写作的章节骨架。

## 执行步骤

1. 明确输入边界。
   - 主题是什么。
   - 面向谁。
   - 目标是什么（说服、说明、叙事）。
2. 给出 3 个候选结构。
   - 线性结构（起-承-转-合）。
   - 问题-分析-方案结构。
   - 场景推进结构。
3. 选择一个主结构并细化到二级标题。
   - 每章给一句目标说明。
   - 每章给 2 到 3 个关键点。
4. 补齐章节连接。
   - 明确每章如何承接上一章。
   - 明确每章结束要把读者带到哪里。
5. 做一次可写性检查。
   - 是否有重复章节。
   - 是否有缺失环节。
   - 是否能直接进入写作。

## 输出模板

```markdown
# 提纲

## 1. [章节名]
- 目标：
- 关键点：
  -
  -
- 转场：

## 2. [章节名]
- 目标：
- 关键点：
  -
  -
- 转场：
```
