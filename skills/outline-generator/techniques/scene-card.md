# 场景卡设计

## 目标
把章节目标拆成可执行场景，减少写作时的失焦和跑题。

## 场景卡核心字段
- scene_id：场景编号。
- pov_character：视角人物。
- objective：本场景要达成的结果。
- conflict：阻碍目标的具体压力。
- outcome：结果走向（+ / - / +/-）。
- plot_beat：推进的剧情节点。
- emotional_arc：情绪变化路径。

## 设计步骤
1. 先定义目标，不先写台词。
2. 给目标配置对等阻力，避免无阻通关。
3. 明确结果对下一场景的影响。
4. 补一条情绪弧线，防止场景只有信息没有体验。

## 快速检查
- 读完场景卡后，能否一句话说清本场景作用。
- 去掉该场景是否会导致剧情断裂。
- 冲突是否来自角色欲望对撞，而非偶然巧合。
