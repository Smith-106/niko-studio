# 🪞 自知之明评估技能包 (Self-Knowledge Eval)

> **核心理念**：伟大的角色弧光来自自知之明的变化——从蒙蔽到觉醒，从否认到接受。评估角色的认知裂痕与觉醒进程。

## 🔧 核心概念

### 自知之明的定义

> 自知之明 = 角色对自身真实状态的认知程度

```
低自知之明：角色不知道自己真正想要什么/害怕什么
高自知之明：角色清楚认识到自己的弱点和需求

故事的功能 = 推动角色从低自知之明走向高自知之明
```

### 认知裂痕

```
认知裂痕 = 角色相信的 - 事实真相

示例：
角色相信：我是个好父亲
事实真相：他把工作放在家庭之上
认知裂痕：对自己的自欺欺人

→ 故事要逼迫角色面对这个裂痕
```

## 📊 自知之明五阶段

### 阶段模型

| 阶段 | 状态 | 角色内心独白 |
|------|------|-------------|
| **Lv.1 否认** | 完全蒙蔽 | "我没有问题，问题在别人" |
| **Lv.2 抗拒** | 初见端倪 | "也许有点问题，但不重要" |
| **Lv.3 挣扎** | 认知冲突 | "我知道有问题，但无法改变" |
| **Lv.4 接受** | 正视真相 | "我确实有问题，我需要改变" |
| **Lv.5 整合** | 完成转变 | "我理解了自己，我已不同" |

### 故事阶段对应

```
        Lv.5 整合
           ↑
Lv.4 接受 │ ← 高潮/自我揭示
           │
Lv.3 挣扎 │ ← 第二幕/中点危机
           │
Lv.2 抗拒 │ ← 第一幕末/激励事件
           │
Lv.1 否认 │ ← 开篇
           └──────────────────→
```

## 🎬 评估维度

### 维度一：认知裂痕深度

```
评估问题：
1. 角色认为自己是什么样的人？
2. 角色实际上是什么样的人？
3. 这两者之间的差距有多大？

评分：
0-2：几乎没有裂痕，角色太自知（无戏剧性）
3-4：轻微裂痕，有成长空间
5-7：明显裂痕，有强烈戏剧冲突
8-10：巨大裂痕，可能导致毁灭性觉醒
```

### 维度二：觉醒催化剂

```
评估问题：
1. 什么事件打破了角色的自欺？
2. 催化剂是否足够强烈？
3. 角色是否被迫面对真相？

优秀催化剂特征：
✅ 无法忽视
✅ 直击核心弱点
✅ 来自亲密关系
✅ 有不可逆后果
```

### 维度三：抗拒强度

```
评估问题：
1. 角色如何回避真相？
2. 抗拒的方式是否符合性格？
3. 抗拒是否逐渐被瓦解？

抗拒类型：
- 否认型：假装没看到
- 攻击型：责怪指出问题的人
- 逃避型：用忙碌/上瘾麻痹
- 合理化型：找借口解释
```

### 维度四：觉醒时刻

```
评估问题：
1. 觉醒是否具有冲击力？
2. 觉醒是否改变了一切？
3. 读者是否与角色一同顿悟？

优秀觉醒时刻：
✅ 情感高峰
✅ 与开篇呼应
✅ 带来价值观转变
✅ 用行动证明（非独白）
```

### 维度五：转变证明

```
评估问题：
1. 觉醒后角色行为如何改变？
2. 改变是否用行动展示？
3. 改变是否有代价？

弱转变：角色说"我变了"
强转变：角色做了以前绝不会做的事
```

## 🎬 案例分析

### 《绝命毒师》Walter White

```
认知裂痕：
- 自我认知：为家庭牺牲的好父亲
- 真实状态：追求权力和认可的人

五阶段：
- 否认："我这么做都是为了家人"
- 抗拒："我可以随时停下来"
- 挣扎："我已经停不下来了"
- 接受："我做这些是因为我喜欢"（最后一集）
- 整合：选择死亡作为救赎

觉醒时刻：
"I did it for me. I liked it. I was good at it."
→ 承认真实动机，完成自知
```
