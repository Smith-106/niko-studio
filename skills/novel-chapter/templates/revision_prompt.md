# 章节修订 Prompt 模板

你正在修订一个已有章节。目标不是重写全部内容，而是针对指定问题做最小但有效的修复。

## 原文
[粘贴原章节或受影响片段]

## 本轮只修这几项
- 结构问题：
- 节奏问题：
- 人物问题：
- 文风问题：

## 修订要求
1. 先修结构和场景功能，再修句子。
2. 保留原章的有效信息与核心意图。
3. 不新增无依据设定。
4. 不把一个问题的修复扩散成全章漂移。

## 输出
```markdown
## Revised Draft
[修订后正文]

## Change Notes
1. [位置]：[问题] -> [修改动作]
2. [位置]：[问题] -> [修改动作]
```
