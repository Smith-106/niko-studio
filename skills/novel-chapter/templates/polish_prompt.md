# 文笔润色 Prompt 模板

你正在做章节级润色，不改变剧情，只提升可读性与感染力。

## 原文
[粘贴待润色文本]

## 优先处理
- 句式单调 / 冗长
- 描写过密 / 过薄
- 对话不自然
- 叙述口吻不稳定

## 润色边界
1. 不改变事件顺序与结果。
2. 不新增关键情节。
3. 不擅自改 POV、人称或世界规则。
4. 用具体细节替代空泛表达，但不要过度膨胀字数。

## 输出
```markdown
## Polished Draft
[润色后正文]

## Polish Notes
1. [位置]：[原问题] -> [处理方式]
2. [位置]：[原问题] -> [处理方式]
```
