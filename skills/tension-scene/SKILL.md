# 场景张力设计 (Tension Scene)

## 适用边界

- 适用：单个场景内的张力入口/触发点/峰值/出口优化。
- 不适用：章节内多场景编排（应转 `tension-chapter`）。
- 不适用：全书关键节点与宏观节奏（应转 `tension-arc`）。

## 概述

帮助作者在单个场景内设计有效的情绪起伏。场景是张力的最小单元，每个场景都应有明确的张力入口、触发点、峰值和出口。

## 使用时机

- 写作单个场景前进行张力规划
- 场景初稿完成后进行张力诊断
- 感觉场景"平淡无味"时进行优化

## 张力要素模型

分析场景时关注四个关键要素：

| 要素 | 说明 | 诊断问题 |
|------|------|----------|
| **入口张力** | 场景开始时的紧张程度 | 开场是否抓人？ |
| **张力触发点** | 引发情绪变化的事件 | 有无明确的转折点？ |
| **张力峰值** | 场景内的情绪最高点 | 高潮是否足够强烈？ |
| **出口张力** | 场景结束时的悬念状态 | 结尾是否留有钩子？ |

## 五种场景张力模式

根据场景功能选择合适的张力模式：

```
1. 渐进上升 ／     适合：冲突酝酿、悬念积累
   - 从平静开始，逐步升级
   - 结尾达到峰值或留下悬念

2. 急剧爆发 │     适合：突发事件、意外转折
   - 快速切入高张力状态
   - 适合动作场景、危机爆发

3. 起伏波动 ∿     适合：谈判对峙、心理博弈
   - 多次小高潮交替
   - 保持读者注意力

4. 高开低走 ＼     适合：危机解除、情绪释放
   - 从高张力开始，逐渐缓和
   - 用于高潮后的过渡场景

5. 平稳推进 ─     适合：信息铺垫、氛围营造
   - 低张力但有必要功能
   - 慎用，避免连续使用
```

## 流程

### 第一步：识别当前张力

阅读场景文本，绘制张力曲线：

```
请提供场景文本或大纲，我将：
1. 标注入口张力等级（1-10）
2. 识别张力触发点位置
3. 标注峰值位置和强度
4. 评估出口张力和悬念感
```

### 第二步：诊断问题

常见场景张力问题：

| 问题类型 | 表现 | 影响 |
|----------|------|------|
| **峰值缺失** | 全程平稳无起伏 | 读者感到无聊 |
| **峰值过早** | 高潮在开头就结束 | 后半段拖沓 |
| **出口泄气** | 结尾比开头还平 | 失去阅读动力 |
| **触发点模糊** | 不知道为何紧张 | 情绪无法代入 |
| **过度紧张** | 全程高强度无缓冲 | 读者疲劳 |

### 第三步：优化建议

针对诊断问题提供具体方案：

1. **调整触发点**：让情绪变化有明确原因
2. **强化峰值**：提升对抗强度、增加赌注
3. **优化出口**：添加悬念钩子或情感落点
4. **重构节奏**：调整段落长短、对话密度

## 张力强度参考

| 等级 | 描述 | 典型场景 |
|------|------|----------|
| 1-2 | 平静/日常 | 休息、闲聊、铺垫 |
| 3-4 | 轻微紧张 | 小分歧、暗示、不安 |
| 5-6 | 中度紧张 | 对峙、争论、抉择 |
| 7-8 | 高度紧张 | 冲突、危机、揭露 |
| 9-10 | 极度紧张 | 生死、崩溃、高潮 |

## 与其他技能的协作

- **→ tension-chapter**：完成场景后，检查章节整体编排
- **← suspense-craft**：悬念技巧可增强场景张力
- **← psychology-craft**：心理描写影响张力感知
