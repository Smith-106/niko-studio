# 心理描写大师 (Psychology Craft)

## 技能定位与边界

| 相关技能 | 边界划分 |
|----------|----------|
| **show-dont-tell** | 展示元原则，本技能是其在心理描写领域的具体应用 |
| **pov-system** | 视角规则限制心理描写的范围（谁的内心可以进入） |
| **dialogue-system** | 对话潜台词，本技能聚焦非对话的心理刻画 |
| **expression-craft** | 微表情属于"外部信号"，与本技能的三维度互补 |
| **four-selves** | 提供四层自我结构，本技能负责具体描写技法 |

**本技能职责**：心理描写的**技法层面**——如何将内心外化/具象化
**不负责**：视角规则（pov-system）、人物结构（four-selves）、对话潜台词（dialogue-system）

## 核心定义

心理描写不仅仅是告诉读者人物"在想什么"，而是通过多种技法将人物的内在世界（情绪、动机、欲望、潜意识）**外化或具象化**，使读者产生深度的移情与共鸣。优秀的心理描写不是"解剖"人物的大脑，而是让读者**"穿上人物的皮肤"**。

---

## 第一原则：拒绝直接陈述，采用展示

### 三层递进表达

| 层次 | 写法 | 信息量 |
|------|------|--------|
| **直白** | "他感到害怕。" | 最低 |
| **比喻** | "他觉得自己像一只即将被狮口吞噬的飞萤。" | 中等 |
| **转喻/暗示** | "他感到了一阵灵魂的战栗，那就是魔鬼的样子。" | 最高（含伦理判断和人物关系暗示） |

### 非语言三维度系统

根据《如何描写情感》，通过以下三者的结合创造立体的心理体验：

| 维度 | 定义 | 示例 |
|------|------|------|
| **外部信号** | 肉眼可见的肢体语言 | 用指关节敲击桌面、避开眼神接触 |
| **内部感觉** | 本能生理反应（无法伪装） | 喉头有想吐的感觉、肚子里不断翻腾 |
| **精神反应** | 思维模式的变化 | 大脑一片空白、思绪混乱无法集中 |

## 核心技法

### 技法一：环境投射与感官过滤

**"一切景语皆情语"** —— 心理描写不一定要写人，可以通过描写人物眼中的环境来折射其心境。

#### 环境与天气的心理化

| 人物心境 | 环境呈现 |
|---------|---------|
| 郁郁寡欢 | 荒凉阴暗、了无生机的风景 |
| 狂躁愤怒 | 暴风雪、雷电交加 |
| 焦虑不安 | 雾色朦胧、视线受阻 |
| 孤独绝望 | 废弃的物品、生锈的咖啡罐、被子弹打穿的塑料桶 |

#### 感官过滤
人物当下的心理状态决定了他注意到什么细节：

```
等待审判、精疲力竭的人：
→ 注意到"雾色朦胧"
→ 无意识地"坐在椅子里扭动"
→ 听到钟声仿佛在敲击他的脊椎
```

#### 陌生化处理
通过独特视角观察熟悉事物，揭示人物独特的心理空间：
- 挖掘机工人的视角 → 看到土地的软硬、缝隙
- 货船船长的视角 → 注意到水面的波纹、风向

### 技法二：内心独白与意识流

#### 拉长紧张段落 (Stretch)
在危机时刻，心理时间会变慢。通过交替描写动作、感官细节和内心想法来"拉长"心理紧张感。

```
❌ 她很着急地找孩子。

✅ 孩子在哪里？
   她推开卧室的门。空的。
   在哭吗？在没有空气的地方吗？
   浴室。也是空的。
   她的手开始发抖，心跳声盖过了其他一切声音。
   衣柜。门被什么东西顶住了——
```

#### 思维的非逻辑性
真实的心理活动往往是跳跃、无逻辑甚至矛盾的：

```
今天是周三。不对，周四。
他说过会来的。
冰箱里还有牛奶吗？不重要。
他不会来了。他从来就没打算来。
我应该买牛奶。
```

#### 梦境与潜意识
梦是潜意识欲望的满足或被压抑思想的释放。描写梦境不仅是写梦本身，更是揭示人物清醒时无法面对的真实心理。

### 技法三：潜文本与双重自我

罗伯特·麦基指出，人物的**文本**（所言所行）与**潜文本**（所思所感）之间的裂痕是心理深度的来源。

#### 表里不一设计

| 层面 | 外在表现 | 内心真相 |
|------|---------|---------|
| 社会自我 | 谈论天气或琐事 | 激烈的道德挣扎 |
| 防御机制 | 开玩笑、轻描淡写 | 深深的恐惧或痛苦 |
| 间接表达 | "手一抖，包子掉在地上" | 面对告白的惊慌 |

#### 内在维度的冲突
心理复杂性来自于矛盾的欲望：

| 冲突类型 | 示例 |
|---------|------|
| 理性 vs 冲动 | 想戒酒却又渴望酒精 |
| 自保 vs 牺牲 | 救自己还是救别人 |
| 爱 vs 恨 | 对同一个人的矛盾情感 |
| 欲望 vs 道德 | 想要却知道不该要 |

## 四个自我模型（麦基）

用于构建多维心理层次：

| 自我层面 | 定义 | 描写切入点 |
|---------|------|-----------|
| **社会自我** | 在社会/职场中戴的面具 | 面对老板、陌生人的表现 |
| **个人自我** | 在亲密关系中的表现 | 面对家人、爱人的表现 |
| **私密自我** | 独处时的真实状态 | 独自一人时的行为和想法 |
| **隐藏自我** | 连自己都不知道的潜意识 | 梦境、失言、非理性行为 |

**应用**：让这四个层面互相冲突，创造维度的丰富性。

## 常见误区与修正

| 误区 | 修正 |
|------|------|
| **心理呓语**：使用临床术语（"他患有承诺恐惧症"） | 用具体的行为和感觉来代替术语 |
| **过度解释**：写完"眼泪涌上眼眶"还要加"她感到非常悲伤" | 不要画蛇添足，信任读者 |
| **陈词滥调**："吓得屁滚尿流"、"心碎了" | 寻找新鲜的、具体的生理体验描写 |
| **直接陈述**："他很紧张" | 描写他"用指关节敲击桌面" |
| **全知视角滥用**：随意进入每个人的脑袋 | 保持视点一致性 |

## AI提示链：心理场景生成

### Step 1: 情境定锚
```
请描述一个需要深度心理描写的场景。
要求先回答：
1. 人物当前面临什么困境/选择？
2. 人物的表面情绪是什么？
3. 人物真正压抑的情感是什么？
4. 人物的"说"与"想"有什么矛盾？
```

### Step 2: 三维度填充
```
请用三维度系统描写人物的心理状态：

1. 外部信号（肢体语言）：
   - 人物的姿态/动作是什么？
   - 有什么下意识的小动作？

2. 内部感觉（生理反应）：
   - 身体哪个部位有感觉？
   - 具体是什么样的感觉？

3. 精神反应（思维模式）：
   - 思维是清晰还是混乱？
   - 有没有跳跃、重复或空白？
```

### Step 3: 环境投射
```
请通过环境描写来折射人物心理：
1. 人物会特别注意到环境中的什么细节？
2. 这些细节如何反映他的心境？
3. 用一个陌生化的比喻来描写他眼中的世界。
```

### Step 4: 潜文本设计
```
请设计人物的表里不一：
1. 人物嘴上说的是什么？
2. 人物心里想的是什么？
3. 有没有一个行为"泄露"了真实想法？
```

## 情感-心理反应速查表

| 情感 | 外部信号 | 内部感觉 | 思维模式 |
|------|---------|---------|---------|
| **恐惧** | 僵住、后退、瞳孔放大 | 胃部紧缩、喉咙发紧 | 思维短路、只想逃跑 |
| **愤怒** | 握拳、咬牙、前倾 | 血液沸腾、太阳穴跳动 | 想攻击、想报复 |
| **悲伤** | 低垂肩膀、避开眼神 | 胸口沉重、四肢无力 | 思维迟缓、回忆涌现 |
| **焦虑** | 坐立不安、反复确认 | 心跳加速、手心出汗 | 思维跳跃、最坏预想 |
| **羞耻** | 低头、遮脸、退缩 | 脸部发热、想消失 | 自我批判、放大细节 |
| **爱** | 靠近、注视、触碰 | 心跳加速、胸口发暖 | 反复想起对方、美化对方 |
| **嫉妒** | 紧盯对方、假装不在意 | 胃部酸涩、胸口发紧 | 比较、贬低、自我怀疑 |
