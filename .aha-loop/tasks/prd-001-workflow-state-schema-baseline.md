# PRD: Workflow State and Schema Baseline

**ID:** PRD-001
**Milestone:** M0

## Overview

Define and freeze typed workflow state contracts with migration-safe versioning to keep stage transitions deterministic and backward-safe.

- Define migration behavior for state evolution.
