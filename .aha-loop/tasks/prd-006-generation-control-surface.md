# PRD: Generation Control Surface

**ID:** PRD-006
**Milestone:** M1
**Status:** Completed

## Overview

Expose generation controls for style, length, and constraints via CLI and persist parameter snapshots as evidence.

## Context

Author control over generation behavior is a non-negotiable vision requirement.

## Goals

- Define CLI parameters for generation controls.
- Persist parameter snapshots next to generated outputs.
- Ensure controls integrate cleanly with workflow state.

## User Stories

To be generated when this PRD is actively expanded.

## Dependencies

- PRD-004: Guided CLI session flow.

## Acceptance Criteria

- [ ] Generation controls are available and validated at CLI boundaries.
- [ ] Parameter snapshots are recorded in quality evidence.
- [ ] Controlled generation outputs remain reproducible from artifacts.
