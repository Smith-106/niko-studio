# PRD: Guided Idea-to-Draft CLI Session

**ID:** PRD-004
**Milestone:** M1
**Status:** Completed

## Overview

Implement a command-first guided session that produces first-draft artifacts from idea input in one run.

## Context

This delivers the primary MVP promise of idea-to-draft in a single guided workflow.

## Goals

- Define deterministic CLI session path from prompt to draft output.
- Persist run metadata and output artifacts for auditing.
- Ensure session can complete under local-first constraints.
