# PRD: Role-Aware Stage Handoff

**ID:** PRD-011
**Milestone:** M3
**Status:** Completed

## Overview

Add role boundaries and deterministic stage ownership to support collaboration in small writing teams.

## Context

Team users need clear stage handoff with auditability and no ambiguity in ownership.

## Goals

- Define role-aware ownership model for workflow stages.
- Enforce explicit handoff transitions between stages.
- Preserve traceability of who approved each gate.

## User Stories

To be generated when this PRD is actively expanded.

## Dependencies

- PRD-010: Chapter release gate scoring.

## Acceptance Criteria

- [ ] Stage ownership is explicit and persisted in workflow artifacts.
- [ ] Handoff transitions are deterministic and validated.
- [ ] Approval trail is available for each stage/gate transition.
