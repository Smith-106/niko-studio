# PRD: Quality Feedback Pipeline

**ID:** PRD-007
**Milestone:** M1
**Status:** Completed

## Overview

Produce scene/chapter-level actionable feedback artifacts from critic and revision stages.

## Context

Quality feedback must be actionable, traceable, and tied to concrete chapter artifacts.

## Goals

- Define feedback schema for severity, anchor, and recommendations.
- Integrate feedback generation into revision and quality stages.
- Persist feedback artifacts for release-gate evidence.

## User Stories

To be generated when this PRD is actively expanded.

## Dependencies

- PRD-005: Checkpointed revision loop.

## Acceptance Criteria

- [ ] Feedback includes scene/chapter anchors and severity levels.
- [ ] Suggested actions are clear enough for revision tasks.
- [ ] Feedback artifacts are linked in quality evidence outputs.
