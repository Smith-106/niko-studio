# PRD: Conflict Triage Workflow

**ID:** PRD-012
**Milestone:** M3

## Overview

Implement structured triage, fix-status tracking, and escalation for consistency and quality issues.

## Context

As quality checks mature, issue triage needs deterministic workflow and traceable resolution status.

## Goals

- Define triage states and transition rules.
- Track issue ownership, fix status, and escalation events.
- Link triage outcomes to release evidence.
